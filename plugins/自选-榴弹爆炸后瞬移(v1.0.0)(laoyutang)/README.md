# 榴弹爆炸后瞬移

## 简介

真人生还者发射的榴弹完成原版爆炸后，将射手瞬移到爆点附近的安全位置。

- 保留原版爆炸伤害、声音和特效。
- 自动检查地面、坡度、站立空间和实体占用，找不到安全位置时不会瞬移。
- Bot、倒地、挂边、被特感控制及梯子上的玩家不会触发瞬移。
- 使用 DHooks 扩展，不依赖 Left4DHooks 插件。

## 可用指令

无。

## 注意事项

- 配置文件位于 `cfg/sourcemod/l4d2_grenade_teleport.cfg`。
- 安全检查不限制 Nav 流程、前进距离或路线可达性。
- 需要 SourceMod 1.11 或更新版本，并安装 DHooks 扩展。
