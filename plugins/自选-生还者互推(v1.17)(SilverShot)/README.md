## 简介

允许幸存者通过右键推击使另一名幸存者进入踉跄状态。随包配置已调整为所有幸存者均可使用，真人和 Bot 之间的推击组合均不拦截。

插件只增加踉跄效果，不造成伤害，也不会直接把正常队友设置为倒地或挂边状态。倒地、挂边等特殊状态没有专门处理。

本包仅面向 L4D2，未包含原插件只在 L4D1 中使用的 `l4d_survivor_shove.txt` gamedata。

## 可用指令

- `sm_sshove`：切换执行者自己的推人能力。
- `sm_sshove 0`：关闭执行者自己的推人能力。
- `sm_sshove 1`：开启执行者自己的推人能力。

以上指令默认要求 Root（`z`）权限，并且只能由游戏内玩家执行。
