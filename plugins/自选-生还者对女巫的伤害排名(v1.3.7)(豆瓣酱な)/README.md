## 简介

在 L4D2 服务器上，女巫死亡或消失时，聊天栏会列出对她造成伤害的生还者。上榜的击杀者用 ● 标记，其余人用 ○ 标记。个人累计伤害不足 1 点时不单独上榜，这部分伤害仍计入总伤害。

## 安装与配置

在面板插件商店安装本条目。服务器需要 SourceMod 及 SDKHooks、SDKTools、DHooks 扩展。可选装同作者的「获取自定义的女巫编号」插件，给排行榜加上女巫编号。

随包配置位于 `left4dead2/cfg/sourcemod/l4d2_witch_ranking.cfg`。修改文件后，下次换图时会载入。可在服务器控制台用 `sm plugins list` 确认插件已加载，再观察一次有生还者参与的女巫击杀结算。约 26 名及以上生还者的服务器，建议按实际满员人数验收排行榜。

该插件无可用指令。
