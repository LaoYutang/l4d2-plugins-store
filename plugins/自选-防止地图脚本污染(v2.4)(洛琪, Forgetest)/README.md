## 使用风险

在 Linux 服务器上，使用本插件期间曾出现服务器进程仍在运行，但游戏服务器无响应、玩家无法连接的情况。目前尚未确认具体原因，请服主根据实际情况谨慎选择是否使用。

由于进程没有退出或崩溃，仅在进程退出或崩溃时触发的自动重启不会生效，可能需要手动重启服务器或容器才能恢复。

相关问题已反馈给插件作者：https://github.com/Mineralcr/L4D2_Public_Plugins/issues/3

## 简介

防止专用服务器上的第三方地图脚本污染，避免地图 B 的全局脚本在地图 A 中被错误执行。

需要原生键值函数库前置。只有与地图 `mission` 文件位于同一 VPK 内的脚本才会被识别为地图脚本，独立脚本类 Mod 不会被拦截。

## 可用指令

- `sm_vpklist`：打开 VPK 白名单/黑名单管理菜单（Root 管理员）。
- `sm_vpkmenu`：同上（Root 管理员）。
