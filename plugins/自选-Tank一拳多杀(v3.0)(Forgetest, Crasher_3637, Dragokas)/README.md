## 简介

允许合作模式下的 Tank 一拳同时命中拳击范围内的多个生还者。

该插件通过 Source Scramble 修改游戏原生 `CTankClaw::SweepFist`
判定，不额外模拟伤害，因此伤害、击飞和方向仍由游戏原生逻辑处理。当前版本为 `3.0`。

## 依赖

- `必选-功能类扩展(sourcescramble.ext)(v0.7.1.4)`

请先安装并启用以上依赖。本插件使用依赖中包含的 `sourcescramble_manager.smx`
加载内存补丁，因此自身仅包含 gamedata 和加载配置，不包含独立 `.smx`。

## 可用指令

该插件无可用指令。

## 注意事项

- 补丁加载后持续生效，不提供游戏模式或开关配置；对抗模式原本已支持一拳命中多个目标，通常不会产生额外变化。
- 在服务器运行期间安装或卸载本插件后，需要重启服务器，或执行
  `sm plugins reload sourcescramble_manager` 重新加载托管补丁。
- 游戏更新后如果目标位置的校验字节不匹配，Source
  Scramble 会拒绝应用补丁并在服务器控制台输出错误，避免直接写入不符合预期的内存位置。
