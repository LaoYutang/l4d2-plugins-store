# 地图待办队列 1.1.0

为战役服务器提供可持久化的地图待办队列。每个待办代表一场战役和指定起始章节；进入后，后续章节由游戏正常推进，完整战役通关后自动进入下一项。

作者：`laoyutang`。支持合作、写实和合作类突变，支持官方及三方战役、任意已安装起始章节、重复待办和一次添加多个地图。列表显示战役、章节及地图代码。

## 安装与升级

需要 SourceMod 1.11 或更高版本，并先安装以下依赖：

- `必选-功能类插件(left4dhooks)(v1.155及以上)(SilverShot)`。
- `必选-功能类插件(原生键值函数库)(v0.4)(fdxx)`。
- `必选-功能类插件(原生投票函数库)(v0.4)(Powerlord, fdxx)`。

将包内 `left4dead2/` 内容合并到服务器的同名目录。配置位于 `cfg/sourcemod/l4d2_map_queue.cfg`，队列保存于 `addons/sourcemod/data/l4d2_map_queue.txt`。

升级时保留现有队列数据和自定义配置；原来的 3 秒切图延迟继续有效。已有 CFG 可以追加 `l4d2_map_queue_reconnect_grace "30.0"`，不追加时也使用默认 30 秒。插件重载后待办保留但处于停止状态，用 `sm_mq run` 或面板“立即启动队列”重新启动。

本插件独立管理待办，也可与 `map_changer` 配合。部署时请保持 `rogue_random_map` 禁用，本插件不处理其兼容。

## 指令与权限

| 指令 | 功能 |
| --- | --- |
| `sm_mq` / `sm_mq status` | 查看启用状态、运行状态、当前项目和待执行数量。 |
| `sm_mq add` | 玩家打开“官方/三方 → 战役 → 章节”添加菜单。 |
| `sm_mq add <地图代码 ...>` | 添加到队尾；RCON 使用带参数写法。 |
| `sm_mq addfront <地图代码 ...>` | 插入队首，多项保持输入顺序。 |
| `sm_mq list` | 查看当前项及全部待办。 |
| `sm_mq remove <地图代码>` | 删除该代码的全部待执行项，保留正在执行的项目。 |
| `sm_mq clear` | 清空并停止，不立即更换当前地图。 |
| `sm_mq run` | 立即启动或恢复队列。执行中且仍在活动战役内时不重新切图；进入其他战役时可切回活动项。 |
| `sm_mq runafter` | 等待当前战役成功通关后开始待办。 |
| `sm_mq pause` | 暂停推进，当前战役继续，通关后不进入下一项；通关前用 `run` 恢复。尚未进入的项目放回队首。 |
| `sm_mq skip` | 执行中跳过当前项并进入下一项；暂停时删除当前项并停止；停止时仅删除队首，不自动启动。 |

拥有换图权限的管理员和 RCON 直接执行修改。普通玩家修改队列时发起原生投票，默认 20 秒，赞成票须多于反对票，同一时间只允许一个投票。查看状态和列表不需要投票。

地图代码必须属于可识别战役且 BSP 已安装。一批添加只要有一项无效就全部取消。控制台或 RCON 可在空服时执行 `run`，以及执行中通过 `skip` 切到下一项，即使服务器正在休眠也直接发起切图。

## 通关与切换规则

- 正常终局仍由原战役成功事件触发，按配置等待，默认 3 秒。
- 缺少原成功事件但出现通关统计时，统计消息补充触发下一项；已经正常等待或请求切图时，统计不会缩短延迟或重复推进。
- 通关后即将返回大厅而待办尚需继续时，兜底接续同一个目标；必要时结束剩余等待，避免玩家先被送回大厅。
- 请求未生效时只有限重试；仍无法进入目标则停止，把尚未进入的项目放回队首，并写明原因。
- 团灭、原地重开和普通章节过图不会消费待办；正常章节重连保留当前项及运行状态。
- 管理员手动换图保留原有续播规则：手动进入的战役通关后仍继续待办。
- 暂停通关或队列耗尽时正常结束，不自动重新启动。完全不产生可信通关信号、或不能识别为终局的地图仍需管理员处理。

## 配置

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `l4d2_map_queue_enable` | `1` | 启用插件。 |
| `l4d2_map_queue_change_delay` | `3.0` | 原终局事件触发后等待秒数，范围 0～60；统计补充触发在下一帧切图。 |
| `l4d2_map_queue_reconnect_grace` | `30.0` | 换图后等待真人重连的缓冲，范围 1～120 秒。 |
| `l4d2_map_queue_vote_time` | `20` | 玩家投票持续秒数，范围 5～60。 |
| `l4d2_map_queue_version` | `1.1.0` | 显示插件版本。 |

## 恢复与排查

换图期间有重连缓冲；缓冲结束后，只要真人已经连接、即使仍在加载，也保留运行状态。确认服务器无人、插件禁用、服务器重启或插件重载时，未完成项回队首并停止。可以再次 `run`；故障待办可用 `remove` 删除，停止状态下的 `skip` 仅删除队首。

地图失效、保存失败及切图失败均保留未执行待办。队列接管 `map_changer` 期间关闭它的终局自动切换，暂停或结束后恢复最新配置。

发现“已停止”时，刷新面板或执行 `sm_mq status`、`sm_mq list`，查看 SourceMod 日志里包含 `[MapQueue] stop` 的停止原因，以及该次换图、加载确认和重连记录。日志能区分空服、重载、模式变化、地图失效、保存失败及切图未生效。
