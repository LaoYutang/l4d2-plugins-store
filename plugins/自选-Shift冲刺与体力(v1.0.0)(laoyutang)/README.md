## 简介

将真人生还者的 Shift（`+speed`）完全接管为冲刺键，并为每名玩家提供独立体力。

- 默认冲刺为玩家当前移动倍率的 2 倍，兼容低血、蹲伏、空中、水中、梯子及其它插件提供的移速倍率。
- 默认满体力 100 点，冲刺消耗 20 点/秒；停止冲刺 1 秒后按 20 点/秒恢复。
- 体力耗尽后必须松开 Shift，恢复到 20 点后重新按下才能再次冲刺。
- 不使用 HUD 或 HintText，仅私聊提示开始冲刺、体力耗尽和体力回满。
- 适用于所有游戏模式，仅真人生还者生效。

## 可用指令

无。

## 注意事项

- 插件启用后，Shift 不再保留原版慢走功能；即使体力不足或当前状态不能冲刺，按住 Shift 也会保持普通跑动。
- 其它依赖 `IN_SPEED`/Shift 组合键的插件可能受到影响。
- 本插件不会修改 `m_vecVelocity` 或 `m_flMaxspeed`，停止冲刺时只恢复仍由本插件持有的移动倍率。
