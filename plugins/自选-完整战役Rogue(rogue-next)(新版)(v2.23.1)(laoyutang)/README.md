# 完整战役 Rogue（rogue-next）2.23.1

作者：laoyutang。适用于 L4D2 完整战役合作模式。

Rogue 将一场战役变成持续成长的挑战：击杀特感积累团队经验，升级后选择 BUFF，搭配士兵、剑客、元素大师、狙神、死神或艺术家的职业能力。成长延续到下一章节，感染者也会随战役时间逐渐变强。

共提供 **6 个职业、65 种 BUFF**，涵盖生存、输出、暴击、元素、全队武器强化和随机奖励。以下数值均为默认设置，服主可以按需要调整。

## 快速开始

1. 输入 `!ba`，首次加点先选择职业，再从三张 BUFF 中选择一张。选择职业免费，本战役只能选择一次。
2. 击杀特感获得团队经验。每次团队升级，每位真人生还者都会获得新的选择次数。
3. 不满意当前三张卡时，可消耗 1 次 ROLL 重新抽取；输入 `!buff` 查看职业、合计加成和剩余资源。

| 指令 | 用途 |
| --- | --- |
| `!ba` / `!buffadd` | 选择职业与 BUFF |
| `!buff` / `!b` | 查看当前加成与成长状态 |
| `!rn_bind` | 获取手动绑定按键的方法 |

推荐 **K 选卡、L 查看**。在自己的游戏控制台粘贴这一行：

~~~text
bind k "sm_ba"; bind l "sm_buff"
~~~

绑定后按一次即可使用。K、L 可以换成其他按键，绑定会覆盖该键原来的用途；插件不会自动绑定，未绑定时使用聊天指令即可。

默认只有存活、未倒地、未挂边且未被特感控制的真人生还者可以选卡，死亡时仍可查看加成。打开或关闭菜单不消耗资源，也不会更换候选；选卡消耗选择次数，ROLL 消耗重抽次数。

## 六个职业

| 职业 | 默认能力 |
| --- | --- |
| 士兵 | 枪械伤害随团队等级提高，每级 +5%；增强枪械直接射击与榴弹伤害 |
| 剑客 | 普通近战攻击速度 +20%，成功挥刀发出剑气，并免疫 Tank 近战缴械；没有初始免控概率；攻速不包括电锯、推击、枪械或换弹 |
| 元素大师 | BUFF 提供的点燃和冰冻概率提高 50%；+2 变为 +3，+4 变为 +6 |
| 狙神 | 狙击距离越远伤害越高，每 100 游戏单位增伤 15%；适用于猎枪、军用连狙、Scout 和 AWP；选择时赠送一把十五连（猎枪） |
| 死神 | 每次特感击杀增加2%通用伤害，同时减少2个百分点伤害减免；按本人本战役累计特感数计算 |
| 艺术家 | 选择后立即获得榴弹发射器；榴弹弹跳次数 +1，分裂概率10% |

职业能力只属于本人。士兵增强榴弹，不增强其他投掷物、爆炸或持续火伤；元素大师仍需先获得相应元素 BUFF 才能点燃或冰冻，不会提高抽到元素卡的机会。狙神保留游戏原有的距离衰减和穿透影响，距离增伤在 2000 游戏单位后停止增长。

士兵职业枪伤（含日常训练）与通用伤害加成、元素卡枪伤代价统一加算，合计最低为零；之后再应用辛辣天塞和暴击倍率。例如士兵10级、没有其他增伤时，一层纵火狂使+50%和-15%合计为+35%，100点枪伤结算为135点。

I级通用「biabiabia」每层枪械伤害+15%，适用于枪械射击和榴弹。它与士兵成长、日常训练、通用增伤及元素卡枪伤代价使用同一个枪伤属性，统一加算后最低为零。例如士兵10级、一层biabiabia与一层纵火狂时，+50%、+15%、-15%合计+50%，100基础枪伤结算150。

士兵、元素大师各可获得三张职业专属 BUFF，剑客、狙神、死神、艺术家各可获得四张。艺术由元素大师和艺术家共用，派大星由除剑客外的五个职业共用；其余专属卡只供对应职业获得。士兵的日常训练每层让每级枪伤额外增加3个百分点，坚韧每层增加30个百分点免控；狙神的爆裂子弹提供狙击范围爆炸。狙神无法获得火之高兴、霜之哀伤、纵火狂、多冻症、烈焰之心、下次一定和破万法，也没有 Rogue 冰火与免控能力；燃烧瓶和原版燃烧子弹仍可使用。剑客不能获得五张冰火元素卡，仍可获得通用免控卡；旧档案保留的元素层数暂停生效，包含其伤害代价。免控卡享受强运加成。

剑客成功挥动普通近战会发出细蓝色剑气，默认总宽96、基础飞行距离300码、速度1100（比原来提高10%）；这里的码按游戏单位计。I级普通专属「剑气纵横」每层增加100码距离，最终最多3000码，`!buff`显示当前合计距离。整个弧线都能命中敌人，中心碰到墙壁或障碍会消失，弧线边缘擦墙可继续飞行，墙后的敌人仍不能被击中。默认每道剑气最多命中1个敌人，接触到最后一个有效目标时就在命中处消失。II级稀有专属卡「剑气透体」每层增加1个名额，最高32个；增加名额后可继续穿透，直到用尽。穿过队友和他们手上的装备不消耗名额。

剑气默认继承挥刀时近战伤害的60%（可配置），并继承暴击属性，享受包甜吗、三刀流、界王拳、通用伤害和辛辣天塞的加成。剑气检测到接触后立即结算伤害，不再等待挥砍结束；同一刀的近战和剑气可分别命中同一存活敌人，该敌人的剑气命中正常消耗剑气名额。打开的门板只遮挡它实际挡住的飞行路线，其他部分的剑气仍能命中。一次剑气对同一敌人只伤害一次；失败挥刀、推击、电锯、枪击和踉跄连点不会额外发射。嗜血狂战每层每次击杀特感回复5实血，剑气击杀同样有效。未加伤害BUFF时，近战500伤害对应剑气300；剑气暴击仍按原暴击倍率计算。

死神与排行榜使用同一份特感击杀数：六种普通特感和Tank各计一次，Witch、普感、BOT与托管BOT击杀不计。选择死神前的本人本战役击杀也立即生效；跨章、死亡、稳定身份重连和D4/繁星保留累计，完整重开归零。伤害加成与现有通用伤害BUFF加算，负面减伤与现有承伤属性加算，枪械、近战、投掷物和火伤沿用原规则。

III级专属「恶魔契约」每层额外提供每杀+2%伤害、-2个百分点减伤，获得时立即按此前累计击杀重算；天赋与契约数值可分别配置。II级专属「从心」每层削减这两项原惩罚的10%，线性叠加，10层免除全部惩罚，超过10层不增加正向减伤，也不影响其他BUFF的惩罚。比如100杀、无恶魔契约时伤害+200%、减伤-200%；一层从心让减伤变为-180%，两层为-160%；另有一层恶魔契约和一层从心时，伤害+400%、减伤-360%。

II级专属「灵魂汲取」每层每次有效特感击杀回复5实血，最多回到本人血量上限。获得前的击杀不补回血，倒地、挂边和死亡时不回血，也不积攒补发；攻击方式不限。

艺术家的榴弹初始基础伤害300、爆炸半径100。每弹跳一次降低当前基础伤害20%，依次为300、240、192、153.6；首次爆炸不衰减。首次碰撞爆炸后，默认还能弹跳1次；撞地面、墙壁、顶面、门和实物均爆炸并消耗本分支次数，弹体穿过人物。II级「乒乓球」每层弹跳次数+1，III级「大场面」每层分裂概率+20个百分点，默认不减少弹跳次数。服主可配置每层扣减次数；设为大于0时启用扣减，实际弹跳最低0，负值保留供后续乒乓球抵扣。分裂概率直接加算，可以超过100%，不乘元素大师或强运的概率倍率。每满100%必定额外增加1颗，剩余百分点再决定是否多增加1颗；弹数包含原弹。

II级「艺术」为元素大师和艺术家共用的爆炸范围属性，每层+100；同时作用于本人榴弹和本人引爆的冰火爆炸。两者初始半径分别100和300，一层艺术后分别为200和400，最终上限均16384。其他职业及BOT没有榴弹弹跳、分裂或艺术范围加成；元素大师可以用艺术提高榴弹范围。

榴弹每次未到末次的碰撞后重新按总分裂概率决定弹数：10%为10%概率变成2颗；100%必定2颗；120%必定2颗并有20%概率变成3颗；200%必定3颗；220%必定3颗并有20%概率变成4颗，之后依此类推。子弹继承父弹已经发生的碰撞次数与伤害衰减进度，各自完成剩余次数，并可以继续分裂；分裂不会恢复初始伤害。同时在飞弹体最多128颗，剩余容量不足时只生成可容纳的部分。末次只爆炸，不再弹跳或分裂；零弹跳时仍有首次爆炸，但没有分裂机会。分裂沿弹跳后的前进方向散开，默认总夹角30度。爆炸只伤感染者，范围内不随距离衰减，墙门和固体遮挡伤害，不伤生还者或道具。

榴弹接受枪械与通用伤害加成，士兵成长、日常训练和元素卡枪伤代价与全伤属性加算后钳零，再应用辛辣天塞和暴击；可由通常的元素BUFF触发冰火能力，实际扣血计入伤害排行。没有任何加成时，首次爆炸基础伤害为300，后续先按弹跳次数衰减，再接受枪械和全伤加成。备用弹药和弹夹沿用游戏设置。

IV级共用专属「派大星」每层爆炸伤害+100%、爆炸半径+100%，士兵、元素大师、狙神、死神、艺术家可获得。作用于榴弹、冰火爆炸和狙神爆裂子弹；多层百分比加算，一层为2倍、两层为3倍。艺术先增加半径，再按派大星放大：一层艺术与一层派大星使榴弹半径400、冰火半径800；爆裂子弹一层派大星的半径600。枪械主目标的直接伤害仍按枪伤属性结算，周边爆炸再应用派大星。冰火爆炸的伤害加成取原点燃者，范围加成取引爆者；普通持续灼烧仍按火伤属性计算。

正常换章、死亡复活、重连，以及使用 D4 或繁星都会保留职业。完整重开或重置战役后可以重新选择。BOT 不选择职业，也不继承真人的职业能力。

首次选择狙神时获得十五连，选择艺术家时获得榴弹发射器。同一战役内退出后重新进入，或真正死亡后复活时，若缺少适合本职业的主武器，会补发对应武器：狙神已有猎枪、军用连狙、Scout或AWP时保留，艺术家已有榴弹发射器时保留；已有武器即使没有弹药，也不会因此补枪或补弹。发放新枪时原主武器掉落在地上，副武器保留。正常过图、倒地后被扶起、普通托管接管及重新搭配BUFF不额外赠送。服主可关闭对应职业赠枪和补发。

## 团队成长与选择次数

团队从 0 级开始。新战役中，每位真人生还者按游戏难度获得初始选择次数，初始 ROLL 为 **5 次**；此后团队每升一级，每人再获得 **1 次选择**。

| 游戏难度 | 初始选择次数 | 击杀经验倍率 |
| --- | ---: | ---: |
| 简单 | 4 | 3 倍 |
| 普通 | 3 | 2 倍 |
| 高级 | 2 | 1.5 倍 |
| 专家 | 1 | 1 倍 |

生还者直接击杀以下目标获得团队经验，BOT 击杀默认也计入。普通感染者不提供经验。

| 击杀目标 | 基准经验 |
| --- | ---: |
| Boomer | 5 |
| Smoker / Spitter | 10 |
| Hunter / Jockey | 12 |
| Charger | 15 |
| Witch | 40 |
| Tank | 100 |

4 人团队第一次升级需要 100 经验，此后每级需求增加 54，单级需求最多 1200，达到后仍可继续升级。生还者人数（含 BOT）会影响升级需求，游戏难度会影响击杀经验。

新加入的玩家可获得本战役的初始选择和当前团队等级应得的基础选择；重连玩家继续使用自己的成长与资源。BOT 没有个人 BUFF，托管和接管不会转移别人的个人成长。

权重是该品质每张卡的权重。**选项概率**指一个候选位置出现该品质的概率；**三选一概率**指整组三张中至少出现一张该品质的概率。一组中可以同时出现不同品质，因此三选一列不能相加。

计算方式：总权重 = 数量 x 权重；选项概率 = 该品质总权重 / 本职业全部总权重；三选一概率 = `1 - (1 - 选项概率)^3`。指定单张 BUFF 的概率为其权重除以本职业全部总权重。服主修改权重后，按本服当前设置重新计算。未选择职业时，通用池为48张，普通/稀有/史诗/传说分别13/13/13/9张。关闭职业后不再获得专属卡：士兵、元素大师、死神、艺术家为48张，剑客仍排除元素卡，为43张（11/11/12/9）；狙神仍排除元素和免控卡，为41张（10/11/12/8）。

### 限定品质的随机奖励

薄葬、激发等限定品质奖励，在当前职业可获得的同品质 BUFF 中等概率抽取。所有自动奖励排除 D4 和繁星，同样遵守职业限制。

| 职业 | 普通奖励卡数 | 稀有奖励卡数 | 史诗奖励卡数（排除 D4） | 传说奖励卡数（排除繁星） |
| --- | ---: | ---: | ---: | ---: |
| 士兵、元素大师 | 13 | 14 | 13 | 9 |
| 剑客 | 12 | 13 | 12 | 8 |
| 狙神 | 10 | 12 | 13 | 8 |
| 死神、艺术家 | 13 | 15 | 13 | 9 |

获得某张指定卡的概率为 `1 / 对应奖励卡数`。风光大葬每层每次有效死亡先有 50% 机会获得稀有奖励，因此指定稀有卡的概率为 `50% / 对应稀有奖励卡数`，另外 50% 为空奖。D4 依照当前职业卡池，排除 D4 和繁星后按剩余卡的当前权重重抽。

### 职业专属搭配

日常训练提高士兵每个团队等级的枪伤成长：一层时每级+8%，两层时每级+11%；团队0级仍没有当前枪伤加成。坚韧与下次一定、破万法共同增加免控概率，再受强运加成，最高100%。

爆裂子弹适用于猎枪、军用连狙、Scout和AWP的直接命中，致死命中也可触发。爆炸以命中敌人的位置为中心，默认半径300游戏单位；未被墙门等固体障碍遮挡的其他敌人，各受到这发子弹加减伤、职业距离增伤和暴击结算后的完整伤害，再按派大星的爆炸伤害加成放大，范围内不随距离衰减。主目标只受原子弹伤害，生还者不受爆炸伤害。

爆裂子弹每层增加20个百分点概率，受强运加成，最高100%；爆裂子弹多层不扩大范围，派大星可提升其伤害与半径；艺术增加榴弹和冰火爆炸半径。爆裂子弹不会引发连锁爆炸，也不消耗其他敌人的燃烧或冰冻状态。

### 灼烧与冰火联动

点燃会在原版燃烧之外，额外造成 **50 点/秒、持续 3 秒** 的灼烧伤害。火之高兴每层只增加 2 个百分点点燃概率；纵火狂每层增加 2 个百分点点燃概率和 25 点基础每秒伤害，枪械伤害降低 10%。烈焰之心每层使灼烧伤害增加 100%。

喷子命中同一敌人的弹丸越多，点燃和冰冻越容易触发。同一枪对同一敌人的结果合并，点燃、冰冻各施加一次，冰火爆炸最多一次；击中不同敌人时分别计算，下一枪可重新触发。

灼烧享受通用伤害加成和辛辣天塞倍率，不暴击，也不享受近战专属加成。纵火狂、多冻症和冰火两重天的伤害代价降低枪械射击与榴弹伤害，包含手枪、喷子与燃烧子弹；近战、电锯、其他投掷物、原版持续火、额外灼烧与冰火爆炸均不受这些代价影响。三种代价与biabiabia、通用伤害加成、士兵职业枪伤（含日常训练）统一加算，随后再应用辛辣天塞和暴击，枪械伤害最低为零；没有其他增伤时，4层冰火两重天使枪械射击伤害降为零，该零伤害枪击无法触发元素，正伤害的其他攻击仍可触发。

**燃烧中的敌人被冰冻，或冰冻中的敌人被点燃，都会触发冰火爆炸。** 中心敌人立即受到本次火焰全部剩余灼烧伤害；基础半径 **300 游戏单位** 内未被墙体或固体障碍遮挡的其他敌人，各受到剩余灼烧的 **50%** 伤害。生还者不受伤。引爆者拥有艺术时，每层再增加 100 范围；多人配合的范围加成只使用最后施加冰冻或点燃、触发爆炸的玩家的艺术，伤害归原点燃者。

冰火爆炸可以暴击，使用原点燃者当前的暴击概率和暴击伤害倍率，强运同样有效。每次爆炸独立判定一次，中心和周边共用结果；默认暴击造成1.5倍伤害，剑圣和幻影刺客可继续提高倍率。

未暴击时，一层纵火狂的灼烧为每秒 75 点，燃烧 1 秒后被冰冻，中心敌人立即受到剩余的 150 点伤害，周边每个敌人受到 75 点伤害。爆炸后中心敌人的冰冻和燃烧结束，周围敌人的原有状态保留；爆炸不会继续引发连锁爆炸。队友之间也可以通过点燃、补冰冻来配合。

冰冻期间特感停止移动、跳跃与发起控制，包括猴子跳跃和牛的冲锋；正在骑乘的猴子会解除骑乘。再次触发冰冻会重新限制动作并刷新持续时间，解冻后恢复行动。冰火爆炸会立即结束中心敌人的冰冻。

敌人死亡后，Rogue的冰冻和燃烧结束，不会继续对尸体触发冰火效果。

重复点燃会刷新持续时间，不叠加多份灼烧；多人点燃时保留较强的火伤。点燃者死亡、断线或离开生还者队伍后，其灼烧结束。燃烧瓶、地图火焰及其他插件的元素效果不参与这项联动。

### 生存与全队强化

- **免控**可以抵抗 Smoker 舌头、Hunter 扑倒、Jockey 骑乘，以及 Charger 的冲撞、抓取和拍地，包括贴墙抓取、撞飞和击倒。
- **血量与回血**均回复实血。获得血量上限加成时回复新增的实血；倒地或死亡期间不持续回血。
- **读档战神**有剩余次数时可以避免倒地并起身，回复实血，随后获得默认 1 秒免伤保护。保护时间不随层数增加，最后一次读档也生效。已用次数不会因复活、重连或正常换章补回。
- **全队换弹与射速**由生还者队伍共享，多名玩家的同类加成可以叠加，BOT 也能受益。榴弹发射器也享受换弹加成；「搞快点」每层使其换弹时间减少3%。
- **强运**提高点燃、冰冻、免控、闪避、暴击和爆裂子弹概率，同类加成可继续叠加，相关概率最高为 100%。

### 随机奖励与重新搭配

- **双生花**增加后续手选卡的收益，包括额外选择和 ROLL；不会复制自动奖励，也不会复制自身、D4 或繁星。
- **激发与业力**共同累积信念。获得激发时，信念达到 3、6、9，分别奖励稀有、史诗、传说随机 BUFF，每次只领取当前最高档的一份；业力只增加信念，下一次获得激发时再领奖。

### 风险与代价

玻璃大炮会增加承受伤害；纵火狂、多冻症、冰火两重天和不动如山也有对应的枪伤或移速代价，搭配时需兼顾生存。

达摩之剑的额外选择从之后的团队升级开始获得，其他选择奖励不会再次增加达摩收益。其 999 点伤害仍受减伤、无敌和读档影响；倒地或挂边期间不触发风险。招灾在倒地或挂边期间也不会召唤 Tank，召唤出的 Tank 被生还者击杀后仍提供经验。

## 时间难度与 Tank、Witch

第一个生还者离开起点安全区域后开始计时。地图无法可靠确认出门时，使用起点门打开或首次有效击杀兼容启动；能确认仍在安全区时，这两项不会提前启动。默认每 **5 个有效分钟** 提升一档难度，正常换章继续累计。

| 感染者血量 | 每档相对初始血量增加 25% |
| 感染者伤害 | 每档相对初始伤害增加 25% |

## 章节灾害

**第一章必定没有灾害，从第二章开始每章判定一次，最多一种。**触发概率按本章开始时的游戏难度分别设置，默认简单10%、普通20%、高级30%、专家40%；触发后五种灾害默认等权抽取，允许连续章节重复。

| 元素浩劫 | 全部感染者元素抗性每档10%，最高50%；包括持续火、燃烧瓶、汽油火、额外灼烧及冰火爆炸，不削弱冰冻控制 |
| 铜墙铁壁 | 全部感染者物理抗性每档10%，最高50%；枪械、近战、电锯、剑气、榴弹、土制炸弹和推击已有伤害生效，推击控制保留；狙神爆裂周边继承减伤后的主弹，不再减一次 |
| 如陷泥潭 | 全体生还者移速每档降低10%，最高30%；与个人移速BUFF乘算，最终倍率最低为基础移速的0.1 |
| 季风 | 普感、六类特感、Tank与Witch地面移速每档增加10%，默认最高30%；与已有移速成长乘算，不提高扑击、冲锋、跳跃或攻击频率，冻结优先 |
| 天罚 | 全体生还者每秒扣D点血，最多3点；先临时血后实血，实血最低1点，不致死、不倒地、不消费读档；不受减伤、闪避或免伤影响 |

天罚在**本章第一个生还者离开起点安全区后**开始，下一章重新等待出门。被控时仍扣，倒地、挂边、死亡和旁观时跳过，不打断治疗、不追补暂停期间扣血。BOT及托管中的生还者同样受到灾害；个人死亡、复活、重连、D4和繁星不改变当前灾害。

聊天公布本章灾害，HUD在右侧原有四行下方空一行显示名称与效果；`!buff`可查看当前灾害和包含泥潭后的净移速。正常过关解除，重新开始战役清空旧灾害，首章仍无灾害。

关闭HUD、Rogue、时间难度或灾害开关会结束本章灾害。重新开启不恢复旧灾害、不在同章补抽，从下一章参与。火抗只降低正常火焰伤害，不改变Tank/Witch原版特殊燃烧致死规则；季风复用游戏速度参数，服务器其他插件后续覆盖参数时尊重其设置。

## 内置战役排行榜

屏幕左侧依次显示 **职业、伤害、特感、玩家名** 四列，前三列紧凑排列，按本战役累计伤害从高到低排名，默认最多15名真人。职业使用 **士兵、剑客、狙神、元素、死神**，尚未选职业时显示“未选”。伤害达到千以上时使用 **K/M/B** 并保留一位小数，例如 **1.2K、123.4M、1.0B**；排名仍按实际累计值计算。姓名放在最后，人数较多时长姓名会缩短。

伤害采用下方伤害统计的实际扣血规则。特感为战役累计击杀六种特感和Tank的数量，不含Witch；BOT击杀和托管BOT击杀不计给真人。死亡和托管期间保留本人这一行，纯旁观者及离线玩家不显示；重新加入后恢复本人累计。正常换章、死亡、重连及D4/繁星保留两项累计，完整重开或新战役清零。

屏幕右侧四行文字左对齐，与排行榜顶部平齐，显示 **章节 n/m、本章路程进度、团队等级、难度等级**。路程按最前生还者的位置计算；难度等级为随战役有效时间增长的档位，关闭时间难度时显示0并标注停用。

## 战役伤害统计与管理员查询

章节和终章结束时不再自动发送聊天伤害榜；关闭HUD也不会恢复自动播报。管理员可使用 `sm_rn_info` 查询，默认列出前 **5** 名的姓名、职业、累计伤害和占比；查询伤害以千分位分隔，例如 **320,000**，占比保留一位小数。

统计真人对普感、特感、Tank和Witch的实际扣血，包含枪械、近战、剑气、投掷物、灼烧、冰火爆炸及爆裂子弹。敌人只剩100血，即使一击造成5,000伤害也只记100；友伤、道具、环境和BOT伤害不计入，托管BOT的伤害也不补给真人。冰火爆炸归原点燃者，爆裂子弹归射手。

占比使用本战役所有参与真人的累计伤害作为总量，前5名之外及已离线玩家的贡献也包含在内；离线玩家保留排名并标注。正常换章、死亡、重连和D4/繁星保留累计，完整重开、新战役及管理员重置清零。

管理员查询只回复执行者，人数由 `rne_damage_stats_top` 设置；查询指定玩家时，可查看他的累计伤害、占比和全员名次。统计关闭后仍可查看此前累计。

## 服主安装与配置

### 安装

需要 **L4D2、SourceMod 1.11 或更高版本、SDKHooks、Left 4 DHooks 1.141 或更高版本**。请先安装与游戏版本匹配的这些基础依赖和 gamedata。

内置HUD复用服务器已有的 **Source Scramble扩展和加载器、EMS HUD补丁gamedata及补丁配置**，这些文件由其他插件提供，Rogue包不重复附带。请确认已有依赖与服务器版本、架构匹配，并已加载 `gamedata/l4d2_ems_hud_sig.txt` 和 `configs/sourcescramble/l4d2_ems_hud_patch.txt`。

1. 在新战役开始前安装。若服务器已加载 `rogue_buff.smx`、`rogue_random_map.smx`，或独立测试插件 `l4d2_grenade_bounce_demo.smx`、`l4d2_blade_wave_demo.smx`，先停用并移出启用目录，保留备用。
2. 解压发布包，把插件名称目录内的 `left4dead2/` 合并到服务器的 `left4dead2/`。使用插件面板时，可直接导入 ZIP。
3. 在服务器控制台执行 `sm plugins list`，确认 `rogue_next` 和 `Source Scramble Manager` 已加载；执行 `sm exts list`，确认 `Source Scramble` 扩展正常。
4. 玩家使用聊天指令或自行绑定按键即可开始。

插件文件：`left4dead2/addons/sourcemod/plugins/rogue_next.smx`。

配置文件：`left4dead2/cfg/sourcemod/rogue_next.cfg`。

发布包仅包含本说明、`rogue_next.smx` 和 `rogue_next.cfg`，共3个文件。安装或升级时合并包内的 `left4dead2/`，HUD继续使用服务器现有依赖。

### 调整配置

所有设置集中在 `cfg/sourcemod/rogue_next.cfg`，可调整职业、初始选择、升级节奏、经验、BUFF 数值、抽卡权重、时间难度、内置排行榜、伤害排名、Tank 强化、进服帮助和选卡条件。各项配置带有用途及默认值说明。

保留已有自定义设置，并参照随包cfg补齐缺失项。只替换SMX不会覆盖现有cfg；若要采用某项默认值，请修改对应配置值。

修改后，在服务器控制台执行：

~~~text
exec sourcemod/rogue_next.cfg
~~~

初始选择、每级选择和初始 ROLL 在新战役、完整重开或管理员重置后生效。初始次数按开局时的游戏难度确定，中途改变难度或初始配置不会补发或扣减当场次数。

职业和大部分 BUFF 设置可在当前战役调整。修改火焰伤害或持续时间会影响之后的点燃；已点燃的敌人继续使用原有伤害与剩余时间。调整配置不会补回已经消耗的资源。

关闭 Rogue 会暂停个人BUFF和时间，保留当前成长及未完成选择；重新开启后恢复这些成长效果。当前章节灾害会结束并清空，再开启后从下一章参与。关闭职业功能时，已选职业和专属 BUFF 保留、能力暂停、专属卡停止获得，死神共用的特感数继续累计，重新开启后按当前累计恢复；剑客的元素限制、狙神的元素和免控限制仍保留。调整配置会清除正在飞行的剑气，之后的挥刀使用新设置。

### 章节灾害配置

~~~text
rne_disaster_enable "1"
rne_disaster_chance_easy "10"
rne_disaster_chance_normal "20"
rne_disaster_chance_hard "30"
rne_disaster_chance_expert "40"
rne_disaster_element_cap "0.50"
rne_disaster_physical_cap "0.50"
rne_disaster_mud_cap "0.30"
rne_disaster_monsoon_cap "0.30"
rne_disaster_punishment_cap "3.0"
~~~

四项游戏难度概率各接受0到100，不强制按大小排序；0不触发，100必定触发，但首章及零强度仍无灾害。五个`rne_disaster_weight_`权重默认各1，0不参与之后的抽取；全设0可得到空灾害池。每种效果还有独立的`_per_tier`每档增量与`_cap`上限，均在cfg中说明。季风上限默认30%，可在0到50%间调整；泥潭最多30%，两种抗性最多50%，天罚最多3血/秒。

概率、权重和强度参数修改从下一章生效，开关关闭立即结束本章灾害。升级旧cfg时补齐本版20项`rne_disaster_`设置，并采用所需的四档概率；只替换SMX不会覆盖服务器已有配置。

### 内置排行榜配置

~~~text
rne_hud_enable "1"
rne_hud_top "15"
~~~

`rne_hud_enable` 设为 `0` 隐藏内置排行榜及右侧信息，并结束本章全部灾害效果；伤害和特感继续累计。`rne_hud_top` 控制实时榜最多人数，范围为 `1` 到 `15`；与管理员查询的人数分别设置。本功能用于单独使用内置排行榜的服务器。

### 伤害排名配置

~~~text
rne_damage_stats_enable "1"
rne_damage_stats_top "5"
~~~

`rne_damage_stats_top` 仅控制管理员查询的最多显示人数，`0` 显示全部有贡献的真人；显示人数不改变占比总量。`rne_damage_stats_enable` 设为 `0` 只暂停伤害统计，保留已有伤害供HUD和管理员查询；特感继续累计，死神成长和灵魂汲取继续生效。重新启用伤害统计不补记关闭期间的伤害，也不重复登记已有击杀。

### 繁星配置

~~~text
rne_fanxing_percent "130"
rne_fanxing_choices "10"
~~~

`rne_fanxing_percent` 为重配总量百分比，`130` 表示1.3倍，最小为 `100`。`rne_fanxing_choices` 为最低额外增加次数，`0` 表示只按比例增长。修改只影响之后触发的繁星，不改变已发放的次数。

### 管理员指令

以下指令需要最高管理员权限，可在服务器控制台使用：

| 指令 | 用途 |
| --- | --- |
| `sm_rn_info [userid 或 SteamID64]` | 查看战役、团队、时间、经验、职业、BUFF名称与层数（统一标题、每行两项）及当前合计属性；无参数查看累计伤害榜和全部真人档案（含离线），带参数查看单人。档案包含累计伤害、占比和全员名次 |
| `sm_rn_xp <非负整数>` | 给团队增加指定数量的经验 |
| `sm_rn_level <非负整数>` | 设置团队等级并清空当前等级进度；降低等级不会回收已有 BUFF 和奖励 |
| `sm_rn_reset` | 清空当前 Rogue 成长，在本地图重新开始 |

合计属性与 `!buff` 一致，包含叠加后的正负加成、实际概率、职业成长、灼烧、爆炸和剩余读档次数，按当前等级与配置计算；全队换弹和射击间隔只汇总当前在生还者队伍的真人贡献。离线档案也可查看个人合计属性，Rogue关闭时明确标明加成未生效。

### 排查帮助

遇到异常时，可临时执行 `rne_debug 1` 开启详细日志，复现后执行 `rne_debug 0` 关闭。请保留同一时间的 SourceMod 错误日志，记录地图、武器或 BUFF、相关配置及出现问题的操作；服务器崩溃时同时保留崩溃记录。

若HUD不显示，先检查上述插件和扩展是否正常加载，并检查服务器控制台的EMS补丁验证信息及SourceMod错误日志；签名不匹配时需更新到适合当前游戏版本的gamedata。

Charger 免控日志位于 `addons/sourcemod/logs/rogue_next_charger.log`，元素日志位于 `addons/sourcemod/logs/rogue_next_elements.log`。
