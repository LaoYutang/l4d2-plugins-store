## 简介

修复 cfg 文件中中文注释可能导致后续内容被异常当作指令执行的问题。
> 在source引擎中，cfg文件的执行无法正确的处理中文，导致中文注释后面的内容被当作指令执行，可能引发错误或各类问题。该插件会自动扫描并在中文注释后添加额外的`//`，避免后续的内容被当作指令执行。

- 插件会监听 `exec` 指令，在执行对应 cfg 前自动检查并修复文件
- 也可以通过管理员指令手动扫描 `cfg` 目录下的所有 `.cfg` 文件。

## 可用指令

- `sm_fix_chinese_cfg` 手动扫描cfg目录下的cfg文件并修复(管理员指令)

## 注意事项

该插件会直接修改存在问题的 cfg 文件，建议安装前先备份重要配置。
