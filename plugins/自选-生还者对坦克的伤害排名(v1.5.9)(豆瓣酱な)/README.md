## 简介

在 L4D2 服务器上，坦克死亡时，聊天栏会按伤害从高到低列出参与攻击的生还者。上榜的击杀者用 ● 标记，其余人用 ○ 标记。此版调整了榜单中玩家名字的读取方式，以减少偶发漏行。

## 安装与配置

在面板插件商店安装本条目。服务器需要 SourceMod 及 SDKHooks 扩展。随包配置位于 `left4dead2/cfg/sourcemod/l4d2_tank_ranking.cfg`，修改文件后，下次换图时会载入。

默认情况下，闲置期间由机器人造成的伤害计入对应玩家。关闭这一选项时，机器人的伤害和击杀标记可能归属不一致。可在服务器控制台用 `sm plugins list` 确认插件已加载，再观察一次坦克击杀结算。约 26 名及以上生还者的服务器，建议按实际满员人数验收排行榜。

该插件无可用指令。
