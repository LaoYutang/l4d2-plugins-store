# [L4D2] Defib using bots（生还者 Bot 电击救援）

## 简介

让生还者机器人使用除颤器救回死去的队友。

作者：`DeathChaos25`、`laoyutang`；插件版本：`1.8`。

- 每秒扫描地图上的队友尸体（`survivor_death_model`），发现 800 单位内有持除颤器的机器人时，命令它赶过去。
- 机器人到达尸体 100 单位内后自动切出除颤器、面向尸体并"按住"电击键，完成救援后复位。
- 电击失败或被打断后有 6 秒冷却，避免机器人卡在反复尝试的状态。
- 附带 4 个 ROOT 权限指令，可手动指挥机器人 AI。

## 来源说明

> [!NOTE]
> 本插件来自整合包"生还者 AI 究极增强"，上游为 AlliedModders 论坛的 [L4D2] Defib using bots（作者 `DeathChaos25`）。本条目保留原作者信息。

商店适配改动：

- 修复尸体遍历逻辑：原代码每轮只检查第一具尸体，若第一具尸体附近没有可用机器人，其他尸体永远得不到处理；现改为成功指派后才停止遍历，第一具尸体无人可用时继续检查后续尸体。
- 修复静态数组初始化的弃用写法（`static shoot[MAXPLAYERS + 1] = 0;` 改为依赖默认零初始化），消除编译警告。
- 电击键定时器回调（`AllowDefib`）增加客户端有效性检查，机器人中途退出时不再写入无效索引。
- 修正武器槽读取的冗余写法（原代码重复调用 `GetPlayerWeaponSlot` 且忽略传入的槽位参数）。
- 使用 SourceMod `1.11.0.6968` 重新编译，0 警告。

## 依赖

- SourceMod 1.11 或更高版本。
- SourceMod 自带的 SDKTools。
- 无需 Gamedata，无需额外扩展。

## 可用指令

全部命令需要 `ROOT` 权限（`ADMFLAG_ROOT`，即 `z` 标志）。

- `sm_resetbots`：完全复位生还者机器人 AI，清除所有机器人指令。
- `sm_regroup`：命令生还者机器人移动到你的位置。
- `sm_attack`：命令生还者机器人攻击你瞄准的特殊感染者。
- `sm_retreat`：命令生还者机器人远离你瞄准的特殊感染者。

## 配置

无可配置的 ConVar（插件仅包含版本号 ConVar `sm_defib_bots_version`）。

## 注意事项

- 与 `l4d2_sb_fix`（生还者 Bot 增强）同装时：`sb_fix` 在危险状态下会拦截机器人切换到除颤器/医疗包，激烈交战中可能影响电击救援的切换时机。
- 与灌油、后撤类插件（`scavengebotsds`、`200IQBots_FlyYouFools` 等）同装时：都通过 `CommandABot` 指挥机器人，指令会互相覆盖。
- 队伍中有人倒地或被控制时，插件会暂停派机器人去找尸体（优先救助活人），属原插件设计。
- 每个扫描周期最多指派一名机器人（找到一具可处理的尸体即停止），避免一帧内下达过多指令。
