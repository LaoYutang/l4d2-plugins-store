# 坦克、特感与女巫血量显示 1.1.0

生还者击中坦克、其他特感或女巫时，可以看到对方的血条。默认在屏幕中央显示剩余血量和上限，可切换到屏幕中下方。坦克死亡时，其他队伍的真人玩家会收到提示。

## 回血后的显示

1.1.0 修复了坦克或其他玩家型特感回血后血条停在旧数值的问题。再次命中时会显示该次受伤后的实际剩余血量，超过 999,999 的血量也能正常显示。

显血插件可以独立使用。搭配支持回血通知的 Rogue 时，如果你在过去 2 秒内击中了某只 486 坦克，且最后看到的仍是这只坦克的血条，它回满时会在原位置刷新一次。换目标、死亡或离场后，这次刷新随即取消。

## 安装和确认

在装有 SourceMod 的服务器上，通过面板插件商店选择并安装本条目。客户端无需安装额外资源。加载后，可在服务器控制台执行 `sm plugins info l4d2_infected_hp.smx` 核对版本。以生还者击中特感，可确认实际显示位置和血量数字。

随包配置位于 `left4dead2/cfg/sourcemod/l4d2_infected_hp.cfg`。可在其中选择显示位置、是否显示数字及启用的感染者种类。原有配置可继续使用。修改配置文件后，在下次地图加载并执行配置时生效。
