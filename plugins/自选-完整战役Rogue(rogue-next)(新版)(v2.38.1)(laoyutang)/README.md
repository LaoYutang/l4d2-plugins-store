# 完整战役 Rogue（rogue-next）2.38.1

作者：laoyutang。适用于 L4D2 完整战役合作模式。本说明供服务器管理员安装、配置插件及向玩家介绍玩法时使用。

Rogue 将一场战役变成持续成长的挑战：击杀特感积累团队经验，升级后选择 BUFF，搭配士兵、剑客、元素大师、狙神、死神、艺术家、十字骑士、领主、工程师或伊甸的职业能力。成长延续到下一章节，感染者也会随战役时间逐渐变强。

共提供 **10 个职业、20 条转职分支、87 种 BUFF**，涵盖生存、输出、暴击、元素、全队武器与救援强化、机枪部署和随机奖励。以下为本版本的玩法规则及默认设置；可调整的项目见随包配置。

## 快速开始

1. 输入 `!ba`，首次加点先选择职业，再从三张 BUFF 中选择一张。选择职业免费，本战役只能选择一次。
2. 击杀特感获得团队经验。每次团队升级，每位真人生还者都会获得新的选择次数。
3. 团队达到13级后，再输入 `!ba` 选择本职业的转职分支。
4. 不满意当前三张卡时，可消耗 1 次 ROLL 重新抽取；输入 `!buff` 查看职业、合计加成和剩余资源。

| 指令 | 用途 |
| --- | --- |
| `!ba` / `!buffadd` | 选择职业、转职与 BUFF |
| `!buff` / `!b` | 查看当前加成与成长状态 |
| `!mg` | 工程师在瞄准位置部署机枪；冷却中会私人提示剩余时间 |
| `!rn_bind` | 获取手动绑定按键的方法 |

推荐 **K 选卡、L 查看**。在自己的游戏控制台粘贴这一行：

~~~text
bind k "sm_ba"; bind l "sm_buff"
~~~

绑定后按一次即可使用。K、L 可以换成其他按键，绑定会覆盖该键原来的用途；插件不会自动绑定，未绑定时使用聊天指令即可。

工程师也可在自己的游戏控制台执行 `bind j "sm_mg"`，自行选择部署按键；未绑定时直接输入 `!mg`。

默认只有存活、未倒地、未挂边且未被特感控制的真人生还者可以选卡，死亡时仍可查看加成。打开或关闭菜单不消耗资源，也不会更换候选；选卡消耗选择次数，ROLL 消耗重抽次数。

## 属性范围与超限显示

`!buff`与管理员合计属性在正常范围内显示一个数值；真正超过上下限时显示“生效值(未截断合计)单位”，例如`机枪射程：1200(1535)码`、`暴击概率：0(-2)%`。恰好等于边界仍显示数字。微小越界会提高显示精度；仍无法区分时，括号内用科学计数显示原值，避免隐藏实际数值。概率原有的取整方式保留。

超过边界的来源继续保留。上限1200、合计1535时，减少100后为1200(1435)，先消耗超出部分；下限0、合计-2%时，增加1个百分点后为0(-1)%。失效职业能力或被石头底座抵抗的新增负面不计入这份合计。卡片说明仍是每层效果，不能与合计属性混读。

本版主要生效范围如下；可配置上限仍由对应设置决定：

| 属性 | 生效范围 |
| --- | --- |
| 最大生命属性加成 | 最低-50点，无玩法上限；在游戏原有生命上限上加算 |
| 全伤、枪伤、近战、火伤、电伤与爆炸伤害加成 | 最低-90%，即对应独立倍率最低0.1倍 |
| 个人移动速度倍率 | 0.1～3倍；先限制个人项，再乘本章泥潭并再次限制 |
| 强运倍率、暴击倍率 | 最低0倍，无玩法上限；各触发概率仍按各自规则结算 |
| 工程师 | 射程100～1200码，部署冷却和持续时间最低5秒 |
| 剑客 | 剑气距离100～3000码、命中1～32个、继承0.5～10倍，近战攻速0.1～3倍 |
| 领主 | 领土半径最低100码，默认上限800码；配置上限不足100时仍按100码执行，保留原设置 |
| 痛并快乐 | 实际持续时间最低1秒，默认6秒；低于1秒按1秒执行 |

分裂概率仍可超过100%；普通概率、工程师爆破概率和各项团队时间减免保留各自上限。有限数值、整数和引擎时长保护继续生效。“无玩法上限”不表示允许溢出。

伊甸的随机增减与命运之骰沿用以上生效范围。负面超过下限时同样保留欠额，之后的正面变化先抵消欠额。命运之骰只改变本次卡牌的数值效果，不改变获得的卡牌数量。

## 十个职业

| 职业 | 默认能力 |
| --- | --- |
| 士兵 | 枪械伤害随团队等级提高，每级 +5%；增强枪械直接射击与榴弹伤害 |
| 剑客 | 普通近战攻击速度 +20%，成功挥刀发出剑气，并免疫 Tank 近战缴械；没有初始免控概率；攻速不包括电锯、推击、枪械或换弹 |
| 元素大师 | 元素共鸣：每系获得另外两系原生概率的50%，共享不递归；一张火+2%的卡得到火2%/冰1%/电1% |
| 狙神 | 狙击距离越远伤害越高，每 100 游戏单位增伤 15%；适用于猎枪、军用连狙、Scout 和 AWP；选择时赠送一把十五连（猎枪） |
| 死神 | 每次特感击杀增加2%通用伤害，同时减少2个百分点伤害减免；按本人本战役累计特感数计算 |
| 艺术家 | 选择后立即获得榴弹发射器；榴弹弹跳次数 +1，基础分裂概率10%，受强运加成 |
| 十字骑士 | 攻击附加自身最大生命2%的伤害；累计8次有效受伤触发「受难爆发」；基础半径150 |
| 领主 | 天赋「领土」：半径150码，圈内全队每秒回复1实血，可用专属卡强化全队 |
| 工程师 | 主动部署自动机枪，默认冷却20秒、持续20秒、射程400码，每0.2秒造成50点基础伤害；伤害不随团队等级提高 |
| 伊甸 | 初始13项个人属性随机7项增加、6项减少；之后获得指定数值BUFF时掷出命运之骰 |

职业天赋由本人持有，领土的圈内支援同时作用于队友。士兵增强榴弹，不增强其他投掷物、爆炸或持续火伤；元素大师需要先获得任意提供原生元素概率的 BUFF，共享得到的概率也能启用另外两系的基础效果，不会提高抽到元素卡的机会。狙神保留游戏原有的距离衰减和穿透影响，距离增伤在 2000 游戏单位后停止增长。

元素共鸣只分享卡牌直接提供的概率。没有概率卡时，火、冰、电均为0%；获得火之高兴后为2%/1%/1%，再获得一层电之沉迷为3%/2%/3%。各系原生贡献先合计，共鸣得到的部分不再分享，随后统一受强运放大并取整，最高100%。火伤加成、持续时间、弹射次数和枪伤代价不会共享；烈焰之心、超导体或雷电法王单独持有时不会产生触发概率。

全伤加成、枪械伤害加成、对应元素伤害加成和辛辣天塞分别计算，各自按适用伤害独立相乘。同一类加成仍按原规则叠加：枪械项合计士兵成长（含日常训练）、biabiabia和元素卡的枪伤代价，倍率最低保留10%；全伤不会抵消枪伤代价。例如基础伤害100、全伤+20%、枪伤-10%时，伤害为100x1.2x0.9=108；再有一层辛辣天塞为216。士兵10级、没有全伤等其他加成时，一层纵火狂使枪械项为+40%，100点枪伤结算为140点。

I级通用「biabiabia」每层枪械伤害+15%，适用于枪械射击、榴弹和工程师机枪，元素大师不可获得。它与士兵成长、日常训练和元素卡的枪伤代价在枪械项内加减；枪械项最低为10%，再与全伤、辛辣天塞及其他适用倍率相乘。

士兵、元素大师各可获得三张职业专属 BUFF，剑客、狙神、死神、艺术家各可获得四张。十字骑士有三张专属卡及两张共享卡。艺术由元素大师、艺术家和十字骑士共用，派大星由士兵、元素大师、狙神、死神、艺术家和十字骑士共用；领主另有六张专属卡，工程师另有五张；其余专属卡只供对应职业获得。士兵的日常训练每层让每级枪伤额外增加3个百分点，坚韧每层增加30个百分点免控；狙神的爆裂子弹提供狙击范围爆炸。狙神无法获得火之高兴、霜之哀伤、纵火狂、多冻症、烈焰之心、四张电系卡、下次一定和破万法，也没有 Rogue 火、冰、电与免控能力；燃烧瓶和原版燃烧子弹仍可使用。剑客不能获得五张冰火元素卡和四张电系卡，仍可获得通用免控卡；旧档案保留的元素层数暂停生效，包含其伤害代价。免控卡享受强运加成。

元素大师无法获得biabiabia、致命一鸡、哎呦喂、剑圣和幻影刺客，全部抽卡、复制和随机奖励均遵守此限制。通用增伤卡与强运仍可获得，元素概率与火、电伤害可以继续成长。关闭职业功能仍保留上述获卡限制。

剑客挥动普通近战会发出细蓝色剑气，默认宽96、距离300码、速度每秒1100码；这里的码按游戏单位计。I级「剑气纵横」每层增加100码距离，最多3000码。每道剑气默认最多命中1个敌人，II级「剑气透体」每层增加1个名额，最多32个。墙门等实物会阻挡剑气伤害，穿过队友和他们的装备不消耗名额。

剑气造成近战伤害的60%，享受近战伤害、通用伤害、辛辣天塞和暴击加成。例如近战伤害为500时，剑气基础伤害为300。同一刀的近战和剑气可以分别击中同一存活敌人，但同一道剑气对同一敌人只造成一次伤害。推击、电锯和枪击不会发出剑气；剑气击杀特感也可触发嗜血狂战回血。

死神按本人本战役的特感击杀数成长，与排行榜一致。六种特感和Tank均计入，Witch、普感及BOT代打的击杀不计入。选择死神前的击杀也计入成长，跨章、死亡、重连和D4/繁星保留累计，完整重开归零。伤害收益与通用增伤叠加，减伤惩罚会增加承受伤害。

III级专属「恶魔契约」每层额外提供每杀+2%伤害、-2个百分点减伤，获得时立即按此前累计击杀重算；天赋与契约数值可分别配置。II级专属「从心」每层削减这两项原惩罚的10%，线性叠加，10层免除全部惩罚，超过10层不增加正向减伤，也不影响其他BUFF的惩罚。未持有石头底座时，比如100杀、无恶魔契约时伤害+200%、减伤-200%；一层从心让减伤变为-180%，两层为-160%；另有一层恶魔契约和一层从心时，伤害+400%、减伤-360%。石头底座对后续承伤增长的抵抗规则见下文。

II级专属「灵魂汲取」每层每次有效特感击杀回复5实血，最多回到本人血量上限。获得前的击杀不补回血，倒地、挂边和死亡时不回血，也不积攒补发；攻击方式不限。

艺术家的榴弹初始基础伤害300、爆炸半径150。每弹跳一次，基础伤害降低20%，依次为300、240、192、153.6。撞地面、墙壁、顶面、门和实物会爆炸，默认首次爆炸后还能弹跳1次。II级「乒乓球」每层弹跳次数+1，III级「大场面」每层为分裂概率增加20个百分点，默认不减少弹跳次数。服主可开启大场面的弹跳代价；当累计扣减超过已有次数时，之后获得的乒乓球会先抵消欠缺次数。职业基础分裂概率与大场面贡献先相加，再乘强运倍率，默认总分裂概率为 `(10 + 大场面层数x20)x(1 + 强运层数x0.5)%`。没有大场面时，一层强运使分裂概率从10%变为15%；一层大场面加一层强运为45%。分裂概率可以叠加并超过100%。

II级「艺术」为元素大师、艺术家和十字骑士共用的爆炸范围属性，每层+100；同时作用于本人榴弹、本人引爆的冰火爆炸及受难爆发。榴弹与冰火爆炸的初始半径分别为150和300，一层艺术后分别为250和400，上限16384；受难爆发基础150，上限800。榴弹额外弹跳和分裂仅艺术家可用；元素大师与十字骑士可以用艺术提高榴弹范围。

榴弹除最后一次爆炸外，每次爆炸都有机会分裂。10%表示有10%机会变成2颗；100%必定2颗；120%必定2颗，并有20%机会变成3颗；200%必定3颗，以此类推，弹数包含原弹。分裂出来的榴弹沿前进方向散开，默认夹角30度，各自使用剩余弹跳次数，伤害不会恢复到初始值，之后仍可继续分裂。全场同时飞行的Rogue榴弹最多128颗，达到上限会减少本次分裂数量。没有额外弹跳次数时只有首次爆炸。榴弹穿过人物，爆炸只伤感染者，范围内伤害不随距离降低，墙门等实物能挡住爆炸。

榴弹接受独立的全伤与枪械伤害倍率，枪械项合计士兵成长、日常训练、biabiabia和元素卡枪伤代价，最低保留10%，再与辛辣天塞、爆炸及其他适用倍率相乘，并按原规则暴击；可由通常的元素BUFF触发冰火能力，实际扣血计入伤害排行。没有任何加成时，首次爆炸基础伤害为300，后续先按弹跳次数衰减，再接受枪械和全伤加成。备用弹药和弹夹沿用游戏设置。

IV级共用专属「派大星」每层爆炸伤害+100%、爆炸半径+100%，士兵、元素大师、狙神、死神、艺术家、十字骑士可获得。作用于榴弹、冰火爆炸、狙神爆裂子弹和受难爆发；多层百分比加算，一层为2倍、两层为3倍。艺术先增加半径，再按派大星放大：一层艺术与一层派大星使榴弹半径500、冰火半径800；爆裂子弹一层派大星的半径600。枪械主目标的直接伤害仍按枪伤属性结算，周边爆炸再应用派大星。冰火爆炸的伤害加成取原点燃者，范围加成取引爆者；普通持续灼烧仍按火伤属性计算。

十字骑士额外最大生命为100加团队等级的10倍；选择职业时补充新增实血，之后每级补充本次增长。生命附伤按每颗有效子弹、霰弹计算，普通近战每次挥击对同一敌人一次；只接受通用增伤和辛辣天塞，枪伤、近战、暴击与派大星不放大这部分伤害。电锯、推击、投掷物和持续伤害不触发附伤。

「受难爆发」要求实际减少实血或临时血。感染者攻击、酸液及全部火焰（含地图、自己和队友的火）均可，每0.5秒最多计数一次；8次后爆炸并清零计数，之后仍按0.5秒间隔累计下一轮；未蓄满次数不会因一段时间未受伤而清空。普通友伤、跌落、其他机关、自损技能、自然虚血衰减以及免伤拦截不算。爆发基础伤害为100加最大生命的80%，接受通用增伤、辛辣天塞和派大星；半径先加艺术再乘派大星，最终上限800。只伤可见感染者，不穿墙、不伤队友。

I级「痛并快乐」每层在有效受伤后6秒内每秒回复最大生命2%，多层相加、不设比例上限，实血最多回满。重复受伤只续时，计数间隔内的有效受伤也能续时；倒地、挂边和死亡结束效果。II级「血气方刚」每层让生命附伤增加1个百分点；III级「忍无可忍」每层减少1次爆发门槛，最低4次，获卡不会直接引爆已有计数。

十字骑士没有Rogue火、冰、电、闪避或免控能力，无法获得对应卡及「奶一口」；「下次一定」「破万法」也不在卡池。旧层数不生效，元素枪伤代价同样禁用。「艺术」「派大星」仍可获得，其他通用回血卡保持原效果。


领主的「领土」初始半径150码，为圈内全队每秒回复1实血。所有领土治疗、增伤及减伤都包含持有者自身，也作用于圈内真人与BOT；多份领土与原有BUFF相加，进出圈按各自来源生效或移除。领土提供治疗、增伤和减伤支援。

I级「领土扩张」每层半径+50码，III级「开疆拓土」每层+150码；先累计范围卡，再应用转职倍率，最终半径上限800码，已获得层数保留。I级「治疗力场」每层回复+1实血/秒，III级「悬壶济世」每层+5；II级「武装防卫」每层通用全伤+10%，II级「坚实壁垒」每层通用减伤+10%，与已有同类BUFF加算。

治疗按当前实血上限封顶，受疗者死亡、倒地或挂边时暂停，不积攒补发。死亡时领土消失，复活恢复；持有者倒地、挂边仍向其他队友提供支援。领主不能获得奶一口、致命一鸡、哎呦喂、剑圣和幻影刺客，复制及随机奖励同样遵守限制。

工程师输入 `!mg` 后在瞄准位置部署自动机枪，准星射线默认最远250码，未命中时仅从末端向下寻找最多37码内的合格地面；最终斜距可超过250码，遇墙不会绕行。机枪自动作战，不能坐上去手动操作。默认每次成功部署后冷却20秒，机枪持续20秒，射程400码，每0.2秒攻击一次，每发基础伤害50；团队等级不增加机枪伤害。每位工程师最多同时存在5座，达到数量上限后，成功部署新机枪会替换最早的一座；位置不适合部署或生成失败时不消耗冷却，也不会拆掉旧机枪。

可以在准星能够命中、表面平整且射击空间足够的移动支撑物上部署，机枪停留在部署时的位置；平台移动或消失后，机枪仍固定在原位。准星未命中且末端下探也未找到地面时，会提示“超出范围”。

机枪重新选敌时，优先六类特感及Tank，其次Witch，最后普感；同类优先最近且可见的目标。选中后持续攻击该目标，直到其死亡、离开射程或被墙门等实物挡住，再重新选敌；其他敌人靠近不会让它中途改打，机枪不能穿墙射击。

机枪接受部署者的通用全伤、辛辣天塞、暴击和有效的队友增伤，实际伤害计入部署者的战役统计。机枪同时接受已有枪械伤害乘区（例如biabiabia），与全伤、辛辣、暴击各结算一次；爆破继承同一发来源预算，不再次乘枪伤。狙神距离、近战和骑士生命附伤不会增强机枪。工程师无法获得Rogue火、冰、电的元素卡，机枪及爆炸也不触发元素；普通公共BUFF仍按各自适用范围作用于本人，机枪不分享全队射速或换弹加成。

工程师有五张专属卡：I级「火力强化」每层使机枪基础伤害固定增加10点；II级「快速架设」每层使基础部署冷却减少2秒；II级「火力覆盖」每层使基础射程增加150码；II级「持久火力」每层为基础持续时间增加3秒，先加秒数再乘分支倍率；III级「爆破弹头」每层增加5个百分点爆炸概率，先合计层数并受强运放大，最终最高25%。例如两层爆破弹头加一层强运为15%，五层即使有强运也最多25%。爆炸继承该发子弹的增伤与暴击，再对周围每个目标分别计算减伤，半径20码，只伤主目标周围其他可见敌人，主目标不会再受一次爆炸伤害，也不会继续引发爆炸。伤害仍受各目标自己的减伤影响。

范围、冷却和持续时间均先累计专属卡，再应用转职效果；部署冷却和持续时间最低5秒，射程100～1200码。阵地先增加火力覆盖的基础射程，再乘1.5。射程超过1200码时，实际仍为1200，未截断合计和全部持卡层数保留；`!buff`显示例如“1200(1535)码”，减少来源时先抵消超出部分。机枪固定在部署位置，工程师需要选择位置并随推进重新架设。

通过聊天、控制台或自绑按键部署时，成功、失败原因和剩余冷却均只提示到本人聊天框。冷却完成时，同时在本人的聊天框和屏幕中部提示一次。

部署需要本人存活、站立、未挂边且未被特感控制。倒地、挂边或被控时，已有机枪继续作战并按原时间到期。死亡、断线、离队、托管接管、换图、完整重置、转职、关闭职业或Rogue及卸载时，机枪和部署冷却清除。D4与繁星清除本人已有机枪，但保留当前剩余部署冷却；职业、转职和新卡组按原规则保留或重配。

正常换章、死亡复活、重连，以及使用 D4 或繁星都会保留职业。完整重开或重置战役后可以重新选择。BOT 不选择职业，也不继承真人的职业能力。

首次选择狙神时获得十五连，选择艺术家时获得榴弹发射器。同一战役内退出后重新进入，或真正死亡后复活时，若缺少适合本职业的主武器，会补发对应武器：狙神已有猎枪、军用连狙、Scout或AWP时保留，艺术家已有榴弹发射器时保留；已有武器即使没有弹药，也不会因此补枪或补弹。发放新枪时原主武器掉落在地上，副武器保留。正常过图、倒地后被扶起、普通托管接管及重新搭配BUFF不额外赠送。服主可关闭对应职业赠枪和补发。

命运之骰每份结果后只显示这份卡直接属性的实际生效增减，多个属性用“、”分隔，过长时按完整属性换行。强运带动的概率等间接变化不在聊天中列出，完整概率可查看状态菜单。聊天中的比例和概率增减用%简写，表示增减百分点，例如+10%即增加10个百分点。承伤比例下降表示少受伤害，增加表示多受伤害；倍率属性显示的是本次倍率变化量。

团队BUFF、四级BUFF，以及资源、整数额度和事件特殊卡保持原效果，不掷骰。D4本身不掷骰；薄葬、风光大葬、激发、颠人等自动赠送的卡也不掷骰，D4带出的自动连锁奖励同样按原效果获得。双生花不复制自动奖励、D4或繁星。

13级分支「豪赌」在初始结果上额外独立随机一轮7项增加、6项减少，原结果不动；除移速外采用当时I级基准的x6，移速为±30个百分点。两轮可以抽到相反方向，最终变化相加。「命运」改用上表的另一套概率，只影响之后的命运之骰。

石头底座抵抗取得它之后，豪赌或命运之骰实际产生的新负面；混合卡反转出来的正面保留。例如已有底座时，玻璃大炮失败造成的输出降低被抵抗，承伤降低仍生效。被抵抗的负面不会留下需要补回的欠额。先产生的负面继续保留，初始随机中的负面也不会被底座清除。

D4和繁星保留伊甸初始与豪赌两轮职业结果，清除旧卡及对应的骰子结果。D4新抽到的合格卡逐个重新掷骰；繁星增加待选次数后，由玩家继续手选。生命上限只有实际净增加时才按增加量补实血，实血最多回到当前上限；上限减少时，超出的当前实血降至新上限。查看、重算或重连不会重复补血。

团队从 0 级开始。新战役中，每位真人生还者按游戏难度获得初始选择次数，初始 ROLL 为 **5 次**；此后团队每升一级，每人再获得 **1 次选择**。

### 人机战斗成长

生还者BOT每个团队等级获得 **10%伤害加成和5%减伤**，0级时没有这两项加成。伤害随等级持续提高，不设上限；这项减伤默认最多80%，16级达到上限。例如10级时，对感染者造成的伤害为原来的2倍，承受伤害减少50%；16级时伤害为2.6倍，承受伤害减少80%，之后升级仍继续增加伤害。

伤害加成作用于BOT攻击感染者的枪械、近战、爆炸和原生持续火焰，不放大BOT造成的友伤。BOT成长减伤同时作用于感染者攻击、友伤和环境伤害，单独与原有受伤效果相乘；Tank不会将这项成长减伤减半。领土支援和章节灾害继续按各自规则生效，80%只限制BOT的等级减伤部分。BOT的血量规则保持原样；真人接管后不再享有BOT加成，托管为BOT后按当前团队等级生效。

每级伤害、每级减伤和减伤上限均可在配置中调整，修改后立即作用于当前BOT。关闭Rogue时暂停这两项加成。

权重是该品质每张卡的权重。**选项概率**指一个候选位置出现该品质的概率；**三选一概率**指整组三张中至少出现一张该品质的概率。一组中可以同时出现不同品质，因此三选一列不能相加。

计算方式：总权重 = 数量 x 权重；选项概率 = 该品质总权重 / 本职业全部总权重；三选一概率 = `1 - (1 - 选项概率)^3`。指定单张 BUFF 的概率为其权重除以本职业全部总权重。服主修改权重后，按本服当前设置重新计算；持有神圣宝珠时，普通卡使用当前普通权重的30%，保留小数比例。神圣宝珠降低的是权重，普通品质的实际出现概率需按降低后的总权重计算。

伊甸和未选择职业时的通用池均为56张，普通/稀有/史诗/传说分别15/16/14/11张。关闭职业后不再获得专属卡：伊甸、士兵、死神、艺术家为56张；元素大师仍排除五张禁卡，为51张（12/14/14/11）；剑客和工程师为47张（12/12/12/11），狙神为45张（11/12/12/10），十字骑士为42张（10/11/11/10）。领主停用职业时为51张（12/14/14/11）。扶一把、争分夺秒、石头底座、神圣宝珠均为全职业通用卡，不受职业启用开关限制。

死亡、复活、正常换章、稳定身份重连及D4／繁星保留转职身份，完整清档后重选；死亡与换章清空临时战斗进度。插件或服务器重启仍不保证保留战役档案。

玩家档案按经过验证的SteamID64关联。身份尚未获取时提示“获取玩家steamid失败，正在重新获取中”，暂时不能使用职业和选卡等个人成长功能；取得身份后自动恢复本战役旧档或建立新档。不使用临时身份档案，插件重载不保留内存档案。

### 职业专属搭配

日常训练提高士兵每个团队等级的枪伤成长：一层时每级+8%，两层时每级+11%；团队0级仍没有当前枪伤加成。坚韧与下次一定、破万法共同增加免控概率，再受强运加成，最高100%。

元素亲和每次获得时，火、冰、电各有三分之一机会被选中，多次获得允许选中相同元素。抽到火时，本次为火+6%、冰+3%、电+3%，其他结果按对应元素排列，再统一受强运影响。每份卡的结果在持有期间固定，死亡复活、正常换章和同战役重连均保留。D4、繁星或完整重置清掉卡时也清掉结果；之后新获得的元素亲和重新随机。

爆裂子弹适用于猎枪、军用连狙、Scout和AWP的直接命中，致死命中也可触发。爆炸以命中敌人的位置为中心，默认半径300游戏单位；未被墙门等固体障碍遮挡的其他敌人，各受到这发子弹加减伤、职业距离增伤和暴击结算后的完整伤害，再按派大星的爆炸伤害加成放大，范围内不随距离衰减。主目标只受原子弹伤害，生还者不受爆炸伤害。

爆裂子弹每层增加20个百分点概率，受强运加成，最高100%；爆裂子弹多层不扩大范围，派大星可提升其伤害与半径；艺术增加榴弹、冰火爆炸和受难爆发半径。爆裂子弹不会引发连锁爆炸，也不消耗其他敌人的燃烧或冰冻状态。

### 电元素与电火联动

电之沉迷和五连鞭各提供每层2个百分点原生电击概率，先加算，再按职业计算共鸣并统一受强运影响，最高100%。例如各一层时，其他可用元素的职业有4%电击概率；元素大师的火/冰/电概率为2%/2%/4%，再有一层强运为3%/3%/6%。火、冰卡和元素亲和提供的原生概率也可让元素大师获得共享电击。超导体和雷电法王本身不提供触电概率。

电击造成额外200点基础元素伤害，默认再弹射2次，普通电链伤害依次为200、170、140。每次弹射减少初始电伤的15%；伤害降至0、次数耗尽或附近没有可传导敌人时结束。超导体每层增加1个额外弹射次数，普通电链在默认衰减下最多额外弹射6次，共命中7个目标。雷电分支改为每跳增加初始电伤30%，默认依次为200、260、320，不受普通电链的衰减次数限制，仍按当前弹射次数结束，最多额外弹射63次。

电弧在敌人之间传导，每跳选择200码内最近、可见的存活感染者；普感、Witch、六类特感和Tank均可传导。普通电链不重复命中同一敌人；雷电分支可在不同敌人之间往返，但不能在同一敌人身上原地连续弹射。墙门等实物能挡住电弧，人物不会阻挡。默认每跳间隔0.12秒，每名玩家触发冷却0.6秒，同时最多一条电链；这些数值均可配置。

五连鞭先增加初始基础电伤，再分别乘雷电法王的电伤倍率、全伤倍率和辛辣天塞倍率，最后受元素抗性影响。枪伤、近战专属加成、烈焰之心、艺术与派大星不放大电击，电击不额外暴击。未转职雷电时，四张电卡各一层的电伤为480、408、336、264，合计1488点，枪伤降低10%。

首目标正在被Rogue灼烧时，电链会携带其100%灼烧每秒伤害和本次点燃的完整时长。每个被弹射且在电击后仍存活的目标重新获得完整燃烧周期：原火150点/秒、完整3秒，即使只剩0.2秒，也会传播150点/秒、完整3秒。火焰伤害归原点燃者，电伤归触电者，分别按实际扣血计入排行；传染火伤不会再次乘传导者的加成。同强度或更强的火焰可刷新，较弱传播不会覆盖或续满已有强火。

雷电分支还会随跳数提高传播的灼烧伤害，每跳增加原始灼烧每秒伤害的30%，时长仍完整继承。例如原火150点/秒，前两次弹射分别传播195、240点/秒，不按上一跳的增强结果复乘。

**同一次攻击同时触发火、冰、电时，先点燃，再传电，最后触发冰火爆炸。** 电链可以继续传播首目标的火焰，即使首目标已被电击杀死或火焰已被冰火爆炸消耗。传播火焰只点燃电击后仍存活的敌人，不会额外触发冰冻、冰火爆炸或新的电链。

### 灼烧与冰火联动

点燃会在原版燃烧之外，额外造成 **50 点/秒、持续3秒** 的灼烧伤害，烈焰分支持续5秒。共享概率启用的点燃也使用这些基础伤害和时长。火之高兴每层只增加2个百分点原生点燃概率；纵火狂每层增加2个百分点原生点燃概率和25点基础每秒伤害，枪械伤害降低10%。烈焰之心每层使灼烧伤害增加100%。

霰弹枪命中同一敌人的弹丸越多，触发点燃、冰冻和电击的机会越高。同一枪对同一敌人最多点燃、冰冻各一次，并触发一次冰火爆炸；电击仍受冷却和每人最多一条电链的限制。击中不同敌人或再次开枪时，可分别触发。

灼烧分别乘烈焰之心的火伤倍率、全伤倍率和辛辣天塞倍率，不暴击，也不享受近战专属加成。烈焰之心只增强火伤，雷电法王只增强电伤；各自的元素加成与全伤、枪伤、辛辣天塞分开计算。纵火狂、多冻症、元素亲和和五连鞭的伤害代价降低枪械射击与榴弹伤害，包含手枪、喷子与燃烧子弹；近战、电锯、其他投掷物、原版持续火、额外灼烧与冰火爆炸均不受这些代价影响。纵火狂、多冻症、五连鞭每层各降低10%枪伤，对所有可获得这些卡的职业生效；元素亲和每层降低20%。这些代价与biabiabia、士兵职业枪伤（含日常训练）在枪械项内统一加减，枪械项倍率最低保留10%，再独立乘全伤、辛辣天塞与其他适用倍率；没有其他增伤时，5层元素亲和仍保留基础枪伤的10%，有效命中可以继续触发火、冰、电。此下限同样适用于Rogue榴弹，不降低独立元素伤害。

**燃烧中的敌人被冰冻，或冰冻中的敌人被点燃，都会触发冰火爆炸。** 中心敌人立即受到本次火焰全部剩余灼烧伤害；基础半径 **300 游戏单位** 内未被墙体或固体障碍遮挡的其他敌人，各受到剩余灼烧的 **50%** 伤害。生还者不受伤。引爆者拥有艺术时，每层再增加 100 范围；多人配合的范围加成只使用最后施加冰冻或点燃、触发爆炸的玩家的艺术，伤害归原点燃者。

冰火爆炸可以暴击，使用原点燃者当前的暴击概率和暴击伤害倍率，强运同样有效。每次爆炸独立判定一次，中心和周边共用结果；默认暴击造成1.5倍伤害，剑圣和幻影刺客可继续提高倍率。

未暴击时，一层纵火狂的灼烧为每秒 75 点，燃烧 1 秒后被冰冻，中心敌人立即受到剩余的 150 点伤害，周边每个敌人受到 75 点伤害。爆炸后中心敌人的冰冻和燃烧结束，周围敌人的原有状态保留；爆炸不会继续引发连锁爆炸。队友之间也可以通过点燃、补冰冻来配合。

冰冻期间特感停止移动、跳跃与发起控制，包括猴子跳跃和牛的冲锋；正在骑乘的猴子会解除骑乘。再次触发冰冻会重新限制动作并刷新持续时间，解冻后恢复行动。冰火爆炸会立即结束中心敌人的冰冻。

击杀敌人的这一枪仍可触发元素联动：电链从敌人死亡的位置继续传导，默认后两次电击伤害为170、140；冰火爆炸仍会伤害附近敌人。尸体不会继续燃烧、冰冻或受到追加伤害，之后再攻击尸体也不会触发元素。

致死攻击同时触发点燃和电击时，电链仍能传播这次火焰的完整伤害和持续时间；同时触发冰冻时，也会产生冰火范围爆炸。若引爆的是之前已存在的火焰，则按它剩余的燃烧时间计算爆炸伤害。

重复点燃会刷新持续时间，不叠加多份灼烧；多人点燃时保留较强的火伤。点燃者死亡、断线或离开生还者队伍后，其灼烧结束。燃烧瓶、地图火焰及其他插件的元素效果不参与这项联动。

### 生存与全队强化

- **免控**可以抵抗 Smoker 舌头、Hunter 扑倒、Jockey 骑乘，以及 Charger 的冲撞、抓取和拍地，包括贴墙抓取、撞飞和击倒。
- **血量与回血**均回复实血。获得血量上限加成时回复新增的实血；倒地或死亡期间不持续回血。
- **读档战神**有剩余次数时可以避免倒地并起身，回复实血，随后获得默认 1 秒免伤保护。保护时间不随层数增加，最后一次读档也生效。已用次数不会因复活、重连或正常换章补回。
- **全队换弹与射速**由生还者队伍共享，多名玩家的同类加成可以叠加，BOT 也能受益。搞快点每层减少2%换弹时间，连射狂人每层减少2%射击间隔，两项分别合计、独立封顶，默认各最多减少20%的时间，10层达到对应上限。射击间隔降至原来的80%时，这一项对应的射击频率为原来的1.25倍。木喷、铁喷、一代连喷和二代连喷均享受这两项加成，榴弹发射器只享受换弹加成；不改变弹匣容量。上限只约束Rogue这两项团队贡献，不影响个人近战攻速、其他WH加成来源或工程师机枪的独立射击间隔。
- **全队救援**由扶一把、争分夺秒共同提供，所有职业均可获得。当前在线且仍在生还者队伍的真人按本人持卡贡献，死亡但未离队时仍计入；旁观、托管与断线期间不贡献，重新接管后恢复本人的贡献。不同玩家与两种卡的减免相加，BOT同样受益，但不提供个人卡加成。默认合计最多减少60%救援时间：以本服5秒基础时间为例，一层扶一把为4.75秒，一层争分夺秒为4.5秒，各一层为4.25秒，达到上限为2秒。`!buff`始终显示全队救援合计的数字，超出当前配置上限时同时显示生效值与未截断合计。原生肾上腺素仍生效，按默认0.5时间系数可进一步降至1秒，因此2秒不是含药时的绝对下限。
- **强运**提高点燃、冰冻、电击、免控、闪避、暴击、爆裂子弹、爆破弹头和艺术家榴弹分裂概率，同类加成可继续叠加。爆破弹头在层数和强运相乘后最高为25%；榴弹分裂可超过100%，继续按每满100%增加一颗、余数概率再增加一颗的规则结算；其余上述概率最高为100%。混乱使用同一分裂概率；和平虽不实际分裂，也用受强运加成后的分裂概率计算首爆的后续期望伤害。

救援按本服实际基础时间计算，不固定为5秒。其他插件或管理员在本章改写救援时间时，Rogue本章暂停调整，下一章配置加载完成后再按新的基础时间计算。正常换章保留两张卡，完整重开清掉卡加成；关闭或卸载Rogue会恢复仍由它控制的原值。该加成不修改电击器时间设置；挂边救援及其他使用相同救援时间设置的插件也可能受到影响，具体表现需在本服确认。

### 随机奖励与重新搭配

- **激发与业力**共同累积信念。获得激发时，信念达到 3、6、9，分别奖励稀有、史诗、传说随机 BUFF，每次只领取当前最高档的一份；业力只增加信念，下一次获得激发时再领奖。
- **薄葬与风光大葬**在被感染者、Witch、口水或队友误伤击杀时发放奖励，自杀和环境死亡不触发。每层薄葬每次死亡获得一个随机普通 BUFF，多层可获得多个，且不消耗选择次数。
- **D4**清空已有 BUFF，将本战役累计应得的选择次数（包括已使用和待选）兑换为随机奖励。每抽到一张，先获得该卡并结算其全部连锁奖励，再继续抽下一张；中途获得的神圣宝珠立即影响后续抽取。重抽次数以使用D4前的累计次数为准，途中获得的额外选择留作本次完成后的待选次数，获得的ROLL正常增加。
- **繁星**清空已有 BUFF，按累计获得的选择次数重配：默认总量为原来的 **1.3倍**，额外增加不足 **10次** 时补足10次，数量四舍五入。累计包括开局、升级、达摩之剑和额外选择卡给过的次数，也包含尚未使用的次数；双生花、薄葬等额外获得的 BUFF 层数不计入。本次选择繁星消耗1次，之后升级照常获得新选择。

| 重配前累计次数 | 重配总量 | 选繁星后待选 |
| --- | --- | --- |
| 20 | 30 | 29 |
| 40 | 52 | 51 |
| 100 | 130 | 129 |

D4 和繁星均保留职业及剩余 ROLL，不补送开局 ROLL；自动奖励不会抽到 D4 或繁星。伊甸初始及豪赌的职业随机结果也保留，清掉的卡牌所对应的命运之骰结果随卡清除。

### 神圣宝珠

神圣宝珠是全职业可获得的传说卡，仅降低持有者个人普通卡的单张抽取权重70%。默认普通权重由100变为30，稀有、史诗和传说的权重保持50、10、1；队友的抽取不受影响。允许多次选择或自动获得，也可由双生花一次获得多份，但效果始终只计算一份，不会进一步降低普通权重。

获得宝珠前已经生成的三张候选保持原样；之后新生成的候选和ROLL才使用新权重。薄葬等限定品质奖励仍在该品质中等概率抽卡，颠人仍直接获得全部合法普通卡，宝珠不取消或减少这些奖励。强运不增加宝珠效果，也不改变选卡权重。

死亡、复活、正常换章和稳定身份重连保留宝珠。D4、繁星和完整清档会清除旧宝珠。D4开始时恢复基础权重，每次抽到一张后先结算该卡的全部连锁奖励；其中重新获得宝珠时，立即降低之后D4抽取的普通权重。繁星清卡后提供待选次数，重新获得宝珠前按基础权重选卡。

### 风险与代价

玻璃大炮会增加承受伤害；纵火狂、多冻症、元素亲和、五连鞭和不动如山也有对应的枪伤或移速代价，搭配时需兼顾生存。

生生不息在真实死亡后默认5秒满血复活，不限次数，多层不叠加；等待时间由 `rne_shengshengbuxi_respawn_delay` 配置（0.1至3600秒），修改影响之后的死亡。死亡期间显示剩余倒计时；等待中团灭仍照常结束。复活保留职业和全部BUFF，按加成后最大生命恢复实血，临时血、黑白和倒地次数清除，已消耗的读档次数保留。主副武器恢复原种类，子弹使用默认生成状态；其他物品不额外恢复，原死亡掉落不追回。薄葬、风光大葬继续按原合格死亡规则发奖。

达摩之剑的额外选择从之后的团队升级开始获得，其他选择奖励不会再次增加达摩收益。其 999 点伤害仍受减伤、无敌和读档影响；倒地或挂边期间不触发风险。招灾在倒地或挂边期间也不会召唤 Tank，召唤出的 Tank 被生还者击杀后仍提供经验。

### 石头底座

石头底座是全职业可获得的传说卡，抵抗获得之后新增的属性负面。获得前已有的负面继续保留；之后再拿同一张负面卡，只抵抗新层的属性代价，正面收益全部生效。例如依次获得「玻璃大炮 → 石头底座 → 玻璃大炮」，两张玻璃大炮都增加伤害，但只有第一张增加承受伤害。重复获得底座只按一份处理，不改变首次生效的时间，也不会清除旧负面。

抵抗范围包含不动如山的移速代价、玻璃大炮的承伤代价，以及纵火狂、多冻症、元素亲和、五连鞭的枪伤代价。服主开启大场面弹跳代价时，也抵抗之后新层扣减的弹跳次数。旧负面即使已把属性压到最低值，超出的欠缺仍保留；之后获得正面加成时先填补这部分欠缺，再增加实际属性，不会因拿到底座而消失。

死神天赋和恶魔契约之后随击杀新增的承伤，也受到抵抗。拿到底座前累计的承伤保留，后续击杀及新获得的契约不再增加这部分承伤；伤害收益仍按当前全部击杀和契约层数成长。从心继续削减留下的旧承伤。例如10杀、1层恶魔契约、没有从心时拿到底座，默认共减少40个百分点减伤；之后杀到20杀仍只保留这40个百分点，再获得一层从心则降为36个百分点。

章节灾害中，拿到底座时已经生效的如陷泥潭减速保留到该灾害结束，之后新发生的如陷泥潭减速受到抵抗。孤立无援只保留获得底座时正在生效的那一次连续孤立：回到队友附近解除后，即使同章再次独处也会抵抗；拿卡时没有孤立，之后首次独处同样抵抗。

伊甸豪赌和命运之骰实际产生的新负面，按取得底座的先后顺序抵抗；伊甸初始负面始终保留，反转成正面的效果不受阻止。其他职业转职分支的属性代价仍生效。底座不抵抗达摩之剑伤害、招灾召唤Tank等非属性风险，也不阻止正常受伤扣血、临时血减少、弹药与技能冷却消耗。领土和圣光等临时效果正常结束，榴弹弹跳等攻击的伤害衰减照常；元素浩劫、铜墙铁壁及季风改变的是敌人能力，天罚直接扣血，这些灾害效果均照常生效。

死亡、复活、正常换章与稳定身份重连保留底座及其抵抗情况。D4、繁星和完整重开会清除底座及抵抗情况；D4与繁星保留累计击杀，因此死神此前被抵抗的承伤可能按保留的击杀数重新出现。再次获得底座时，以当时已有的负面为准重新开始抵抗。

D4的随机奖励按实际获得顺序逐张结算，底座前的负面保留，之后的负面抵抗。例如20杀的死神在D4清卡后，默认天赋先恢复为减少40个百分点减伤；若先获得恶魔契约再获得底座，就保留天赋与该层契约合计减少80个百分点减伤。繁星清卡后提供待选次数，由玩家继续手动选卡，同样按每次实际获得的先后顺序结算。

## 时间难度与 Tank、Witch

第一个生还者离开起点安全区域后开始计时。地图无法可靠确认出门时，使用起点门打开或首次有效击杀兼容启动；能确认仍在安全区时，这两项不会提前启动。默认每 **5 个有效分钟** 提升一档难度，正常换章继续累计。

| 项目 | 默认增强 |
| --- | --- |
| 感染者血量 | 每档相对初始血量增加25% |
| 感染者伤害 | 每档相对初始伤害增加25% |
| Tank 移速 | 每档相对初始移速增加 8% |
| Tank 额外血量 | 4 人团队在初始档位为原血量的 2 倍，并随人数和时间难度调整 |
| Witch 额外血量 | 4 人团队在初始档位为原血量的 1.5 倍，并随人数和时间难度调整 |
| Tank 近战缴械 | 使用近战攻击 Tank 时，有 20% 概率被缴械，掉落武器可以重新拾取；剑客默认免疫 |

Tank 和 Witch 的额外血量分别设置，人数包含 BOT 和死亡后仍留在求生者队伍的玩家；8 人队伍的出生血量为相同时间档位下 4 人队伍的 2 倍。血量在出生时确定，已在场的感染者不会因升档或人数变化增加血量。Witch 默认额外血量倍率为 **1.5**，使用 `rne_witch_hp_factor` 调整；`rne_witch_count_scaling` 设为 `0` 可关闭 Witch 的人数缩放。

回安全屋、倒地、死亡或旁观不会暂停计时。关闭 Rogue、关闭时间难度或服务器没有真人连接时暂停；默认难度档位不设上限。服主可单独关闭时间难度，继续使用 BUFF 和团队升级。

## 章节灾害

**第一章必定没有灾害，从第二章开始每章判定一次，最多一种。**触发概率按本章开始时的游戏难度分别设置，默认简单0%、普通20%、高级40%、专家60%；触发后六种灾害默认等权抽取，允许连续章节重复。保留旧cfg的服务器需自行修改三个概率键并执行配置：`rne_disaster_chance_easy "0"`、`rne_disaster_chance_hard "40"`、`rne_disaster_chance_expert "60"`；普通难度保持20%，仅更新SMX不会覆盖已有cfg。

效果强度使用本章开始时的**时间难度档位D**。游戏难度决定概率，时间难度决定强度；本章中途改难度、升级时间档位或调整灾害数值，不重新抽取或增加本章灾害。D为0时没有有效灾害。

| 灾害 | 默认效果 |
| --- | --- |
| 元素浩劫 | 全部感染者元素抗性每档10%，最高50%；包括持续火、燃烧瓶、汽油火、额外灼烧、电击及冰火爆炸，不削弱冰冻控制 |
| 铜墙铁壁 | 全部感染者物理抗性每档10%，最高50%；枪械、近战、电锯、剑气、榴弹、土制炸弹和推击已有伤害生效，推击控制保留；狙神爆裂周边继承减伤后的主弹，不再减一次 |
| 如陷泥潭 | 全体生还者移速每档降低10%，最高30%；个人移速先限制在0.1～3倍，再乘泥潭效果，最终倍率仍限制在0.1～3倍 |
| 季风 | 普感、六类特感、Tank与Witch地面移速每档增加10%，默认最高30%；与已有移速成长乘算，不提高扑击、冲锋、跳跃或攻击频率，冻结优先 |
| 天罚 | 全体生还者每秒扣D点血，最多3点；先临时血后实血，实血最低1点，不致死、不倒地、不消费读档；不受减伤、闪避或免伤影响 |
| 孤立无援 | 周围500码没有活着的队友时，伤害减免每档降低10%，最多降低100%；与个人减伤加算，净减伤可为负 |

天罚在**本章第一个生还者离开起点安全区后**开始，下一章重新等待出门。被控时仍扣，倒地、挂边、死亡和旁观时跳过，不打断治疗、不追补暂停期间扣血。BOT及托管中的生还者同样受到灾害；个人死亡、复活、重连、D4和繁星不改变当前灾害。

孤立无援按三维距离计算，500码按游戏单位计并包含边界，隔墙也算；倒地、挂边、被控队友和BOT均能解除附近队友的孤立，死者和旁观者不算。自己倒地或挂边不免除惩罚，仅剩一人时照常生效。每秒更新位置状态，返回队友附近后解除；强度和范围在章初确定，本章不随时间升档或配置修改变化。原有50%减伤受到30%孤立惩罚后剩20%，没有减伤时会额外承伤；Tank只穿透合并后正减伤的一半。闪避和读档保护仍按原规则生效；生生不息不再提供免伤。

孤立生效期间，中下方提示框只显示“孤立无援”；解除后停止刷新，提示自然淡出。缴械等短提示会暂时优先显示；其他插件的提示也可能覆盖该提示框。右侧显示“天灾：孤立无援”和“独处时减伤降低 30%”，数字按本章实际强度变化。

本章灾害可在聊天、右侧HUD和 `!buff` 中查看。正常过关后灾害结束，重新开始战役后第一章仍无灾害。

孤立无援的四项配置为 `rne_disaster_weight_isolation`（默认1，0不参与）、`rne_disaster_isolation_per_tier`（默认0.10）、`rne_disaster_isolation_cap`（默认1.00）和 `rne_disaster_isolation_radius`（默认500，范围1至16384）。旧cfg需补齐新键并保留其他自定义值。

关闭HUD、Rogue、时间难度或灾害开关会结束本章灾害。重新开启后从下一章参与抽取。元素抗性不改变Tank和Witch原版的特殊燃烧死亡规则；其他插件也会影响感染者移速，服主应结合本服设置调整季风强度。

## 内置战役排行榜

屏幕左侧显示职业、战役累计伤害、特感击杀数和玩家名，按伤害从高到低排名，默认最多15名真人。元素大师、艺术家和十字骑士的职业简称为“元素”“艺术”和“骑士”。大额伤害使用K/M/B缩写，长姓名可能缩短。

伤害采用下方伤害统计的实际扣血规则。特感为战役累计击杀六种特感和Tank的数量，不含Witch；BOT击杀和托管BOT击杀不计给真人。死亡和托管期间保留本人这一行，纯旁观者及离线玩家不显示；重新加入后恢复本人累计。正常换章、死亡、重连及D4/繁星保留两项累计，完整重开或新战役清零。

屏幕右侧显示当前章节、本章路程进度、团队等级和时间难度等级。路程按最前生还者的位置计算；关闭时间难度时显示停用。

服主可在左上角显示一行自定义文字，默认留空不显示；设置方法见下文“左上角自定义文字”。

## 战役伤害统计与管理员查询

管理员可使用 `sm_rn_info` 查询战役伤害榜，默认列出前5名的姓名、职业、累计伤害和占比。插件不会在章节或终章结束时自动发送聊天伤害榜。

统计真人对普感、特感、Tank和Witch的实际扣血，包含枪械、近战、剑气、投掷物、灼烧、电击、电火传染、冰火爆炸、爆裂子弹及工程师机枪。敌人只剩100血，即使一击造成5,000伤害也只记100；友伤、道具、环境和BOT伤害不计入，托管BOT的伤害也不补给真人。冰火爆炸归原点燃者，爆裂子弹归射手，工程师机枪及其爆炸归部署者。

占比使用本战役所有参与真人的累计伤害作为总量，前5名之外及已离线玩家的贡献也包含在内；离线玩家保留排名并标注。正常换章、死亡、重连和D4/繁星保留累计，完整重开、新战役及管理员重置清零。

管理员查询只回复执行者，显示人数可在配置文件中调整；查询指定玩家时，可查看他的累计伤害、占比和全员名次。统计关闭后仍可查看此前累计。

### 升级与回退

升级前备份现有SMX、cfg和两份gamedata，在新战役开始前安装随包的全部运行文件；保留原cfg时，按新版注释补入工程师设置及五张卡的设置，保留其他自定义值。仅替换SMX不会覆盖既有cfg。工程师无需额外安装自动机枪插件或翻译文件。游戏文案固定使用中文，不随服务器或玩家语言切换，无需修改服务器全局语言设置。

保留旧cfg升级时，手动补入`rne_hud_text ""`，默认不显示顶部文字；其余自定义值继续保留。

保留现有cfg时，不会自动覆盖管理员的自定义值。若希望采用火力覆盖当前每层150码的默认值，请手动将`rne_engineer_range_per_stack`设为`150`，再在服务器控制台执行`exec sourcemod/rogue_next.cfg`；需要其他增量时可继续保留自定义值。

旧cfg需补入`rne_team_reload_cap "0.20"`和`rne_team_firerate_cap "0.20"`两项独立上限。若希望采用当前基础机枪射程和两张团队卡的默认值，请手动设置`rne_engineer_radius "400"`、`rne_reloadspeedmultiple_surv "0.02"`和`rne_fireratemultiple_surv "0.02"`，然后执行`exec sourcemod/rogue_next.cfg`。原有自定义值可继续保留，更新SMX不会自动覆盖这些设置。

旧版遗留的`addons/sourcemod/translations/rogue_next.engineer.phrases.txt`不会影响新版，可保留用于回退；不再使用旧版时也可删除。

需要回退时，卸载新版Rogue后恢复同一旧版本的完整运行文件，再重新开始战役；不要将不同版本文件混装。回退到附带工程师翻译的旧版时，也须恢复该旧包的翻译文件。卸载会清理工程师机枪，当前战役成长不会跨插件重载保存。旧版本交付包应保留，回退不需要删除其他插件。

### 调整配置

原有配置默认值保持。领土实际半径最低100码；上限`rne_lord_radius_cap`的既有配置输入1～800码保持。实际最低100码优先：例如配置上限为50时，保留50这个设置，实际按100码执行，显示与执行使用同一边界。来源合计400码时显示100(400)码；之后将上限恢复800，合计来源未变时即生效400码，不丢弃此前受限的余量。工程师低于100码的基础射程、低于5秒的最终寿命，以及剑气低于100码的距离、低于0.5倍的继承，仍可保留原输入，但实际执行会按本版属性下限限制。`rne_pain_pleasure_duration`的实际生效时间最低1秒，默认6秒。爆裂子弹继续使用共同爆炸伤害倍率，最低0.1倍，没有新增独立倍率设置。

伊甸沿用现有I级BUFF设置作为初始和豪赌的数值基准，移速分别固定为±10和±30个百分点；命运之骰的两套概率与效果倍率固定。调整BUFF配置会改变卡牌当前的数值效果，也会影响此后首次选择伊甸或选择豪赌时的变化量；此前已经确定的两轮职业随机数值保留。

关闭`rne_profession_enable`会暂停伊甸职业随机加成及命运之骰的数值效果，已持有的通用卡暂按普通层数生效，保存的随机结果不删除；重新开启后恢复原结果。停用职业期间新获得的卡按普通效果获得，不补掷命运之骰。

领主有14项辅助设置，基础半径150码、最终上限800码、基础每秒回复1实血。若曾安装未采用的2.32.0测试包，请在加载新版前按本版配置清理旧领土攻击、攻速及分支参数，并将保留的领土半径和上限更新为本版值；其他正式参数的自定义值应保留。旧测试方案不作为本版玩法或战役档案迁移依据。

### 左上角自定义文字

`rne_hud_text`默认留空不显示，在Rogue内置HUD正常显示时出现，与现有排行榜共用`rne_hud_enable`总开关、战役显示条件和观看范围。文字更新后刷新显示，清空后隐藏，不改变战斗属性。

在服务器控制台设置或更新文字：

~~~text
rne_hud_text "自定义文字"
~~~

清空文字：

~~~text
rne_hud_text ""
~~~

也可在`cfg/sourcemod/rogue_next.cfg`中修改该行，再在服务器控制台执行`exec sourcemod/rogue_next.cfg`。修改配置文件不会自动覆盖服务器当前设置，执行配置后生效。

文字最多127个UTF-8字节，只允许单行，首尾空白自动去除，纯空白不显示。超长、无效UTF-8、含嵌入换行或控制字符的值会被拒绝，保留此前有效设置。文字中的`%`按原样显示。

其他EMS顶部HUD可能占用相同位置或显示槽位；出现重叠或覆盖时，由服主协调相关HUD设置。

### 管理员指令

以下指令需要最高管理员权限，可在服务器控制台使用：

| 指令 | 用途 |
| --- | --- |
| `sm_rn_info [userid 或 SteamID64]` | 查看战役状态、团队成长、职业、BUFF层数、合计属性和伤害排名；无参数查询全体真人（含离线），带参数查询指定玩家 |
| `sm_rn_xp <非负整数>` | 给团队增加指定数量的经验 |
| `sm_rn_level <非负整数>` | 设置团队等级并清空当前等级进度；降低等级不会回收已有BUFF和奖励 |
| `sm_rn_reset` | 清空当前Rogue成长，在本地图重新开始 |

合计属性与 `!buff` 一致，包含叠加后的正负加成、实际概率、职业成长、灼烧、爆炸和剩余读档次数。离线档案也可查询，Rogue关闭时会标明加成未生效。

### 排查帮助

插件无法使用时，先检查 `sm plugins list`、`sm exts list` 和SourceMod错误日志，确认依赖加载成功、配置与gamedata路径正确。HUD不显示时，还应检查EMS补丁验证信息；签名不匹配时使用适合当前游戏版本的gamedata。

需要复现异常时，可在服务器控制台临时执行 `rne_debug 1` 开启详细日志，复现后执行 `rne_debug 0` 关闭。记录地图、武器或BUFF、相关配置及操作步骤，并提供版本、系统、相关插件及脱敏日志；崩溃时保留崩溃记录。

十字骑士的受伤、计数和爆发记录写入SourceMod普通日志，可搜索 `KNIGHT_HURT`、`KNIGHT_COUNTER`、`KNIGHT_BURST`。Charger免控日志位于 `left4dead2/addons/sourcemod/logs/rogue_next_charger.log`，元素日志位于 `left4dead2/addons/sourcemod/logs/rogue_next_elements.log`。

部署距离参数只供管理员配置，不在玩家属性界面显示。升级保留旧cfg时，`rne_engineer_deploy_distance`可能仍为200，需手动改250并执行配置；补入`rne_engineer_lifetime_per_stack "3"`。工程师提示固定中文，无需额外翻译文件。机枪使用细红色短时曳光，音效及伤害规则保持。
