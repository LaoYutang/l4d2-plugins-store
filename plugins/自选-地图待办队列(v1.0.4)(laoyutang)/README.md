## 简介

为战役服务器提供可持久化的地图待办队列。每个待办代表“一场战役 + 指定起始章节”：进入指定章节后，后续章节仍由游戏正常推进；完整战役通关后，插件自动进入下一项。

作者：`laoyutang`；版本：`1.0.4`。

- 支持合作、写实和合作类突变模式。
- 支持官方战役与三方战役，允许从任意已安装章节开始。
- 支持重复项目、一次添加多个地图、插入队首、删除、清空、暂停、立即执行和通关后执行。
- 队列保存于 `addons/sourcemod/data/l4d2_map_queue.txt`，服务器重启或插件重载后仍会保留。
- 列表会显示战役名称、章节名称和地图代码，便于玩家确认内容。

## 依赖

- `必选-功能类插件(left4dhooks)(v1.155及以上)(SilverShot)`
- `必选-功能类插件(原生键值函数库)(v0.4)(fdxx)`
- `必选-功能类插件(原生投票函数库)(v0.4)(Powerlord, fdxx)`

请先安装并启用以上依赖。插件需要 SourceMod 1.11 或更高版本。

## 可用指令

- `sm_mq` 或 `sm_mq status` 查看插件启用状态、执行状态、当前项目和待执行数量。
- `sm_mq add` 玩家无参数执行时，依次选择“官方/三方战役 → 战役 → 章节”。只有这个无参数指令会打开菜单。
- `sm_mq add <地图代码 ...>` 将一个或多个地图添加到队尾，RCON 请使用这种带参数写法。
- `sm_mq addfront <地图代码 ...>` 将一个或多个地图插入队首，多项保持输入顺序。
- `sm_mq list` 显示当前执行项和全部待办。
- `sm_mq remove <地图代码>` 删除待执行列表中该代码的全部项目，不影响正在执行的项目。
- `sm_mq clear` 清空队列并停止执行，不立即更换当前地图。
- `sm_mq run` 立即启动队列并切换到队首指定章节；执行中且当前地图属于活动战役时不会切图；当前地图属于其他战役或无法识别时，会重新切回活动项。处于 `runafter` 等待状态时会改为立即执行。
- `sm_mq runafter` 等待当前战役成功通关后，再进入队首指定章节。
- `sm_mq pause` 暂停队列推进。当前战役继续正常进行，通关后不会进入下一项；后续待办保持不变。通关前可用 `sm_mq run` 恢复连续执行。
- `sm_mq skip` 跳过当前待办。队列执行中会继续切换到下一项；暂停状态下只删除当前项并保持停止；停止状态下可用来删除队首的故障地图。

地图代码必须精确存在于战役数据中，并且对应 BSP 已安装。一次添加多个地图时，只要其中一个无效，本次添加就全部取消。队列允许出现重复项目。

拥有换图权限的管理员和 RCON 会直接执行修改操作。普通玩家执行 `add`、`addfront`、`remove`、`clear`、`run`、`runafter`、`pause` 或 `skip` 时会自动发起原生投票；投票默认持续 20 秒，赞成票必须多于反对票，同一时间只允许一个投票。`status` 和 `list` 不需要投票。

## 配置

配置文件位于 `cfg/sourcemod/l4d2_map_queue.cfg`。

- `l4d2_map_queue_enable "1"` 启用或禁用插件。
- `l4d2_map_queue_change_delay "3.0"` 战役通关后进入下一项前等待的秒数。
- `l4d2_map_queue_vote_time "20"` 普通玩家投票持续的秒数。
- `l4d2_map_queue_version` 只读版本号，当前为 `1.0.4`。

## 执行与恢复规则

- 插件只在最终章节收到战役成功事件后消费当前项；团灭、重开和普通章节过图不会消费队列。
- 管理员在队列执行期间手动换图不会停止队列。手动进入的战役通关后，插件仍会继续下一项。
- 下一项地图文件失效时，插件会停止并保留该项；修复地图后执行 `run`，或使用 `skip`、`remove` 处理。
- 服务器重启、插件重载或最后一名真人离开时，未完成项目会放回队首并停止。服务器有人后需要再次执行 `sm_mq run`。
- 队列执行或等待期间，如果同时安装了 `map_changer`，插件会临时关闭它的终局自动换图，队列停止或完成后恢复其最新配置；无需修改 `map_changer`。
- 本插件不处理 `rogue_random_map` 的兼容，部署时请保持该插件禁用。
