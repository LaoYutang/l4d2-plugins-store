# 危险女人（Witch 善变连杀）

## 简介

Witch 被惊扰后会定时重新选择最近的活动生还者；击倒当前目标时会立即换人，从而连续追击队伍中的其他玩家。

作者：`laoyutang`；版本：`1.1.0`。

`1.1.0` 新增 Witch 击倒生还者后的可配置回血功能。

`1.0.1` 修复可见性射线命中候选玩家时被误判为不可见，恢复 Witch 击倒玩家后的立即换目标。

- 支持固定间隔和随机间隔，随机模式默认在 2～6 秒之间重新抽取时间。
- 按直线距离从近到远检查其他活动生还者，优先追击第一个可见目标；没有可见的新目标时会刷新当前目标。
- 真人和 Bot 均可成为目标，倒地、挂边或死亡的生还者不会被选择。
- Witch 每次击倒生还者后默认回复 100 点生命值，可配置为 0 关闭。
- 通过灭火和零伤害伪点燃更换目标；除可配置的击倒回血外，不包含固定寿命、传送或跟随功能。
- 周期性伪点燃会刷新 Witch 的原生燃烧时间，因此正在循环追击的 Witch 不会被火焰或燃烧瓶烧死。

## 依赖

- SourceMod 1.11 或更高版本。
- SourceMod 自带的 SDKTools 和 SDKHooks。

不需要 Actions、Left4DHooks 或额外 Gamedata。

## 可用指令

无。

## 配置

配置文件位于 `cfg/sourcemod/l4d2_witch_kill_chain.cfg`。

- `l4d2_witch_kill_chain_enable "1"` 启用或禁用插件。
- `l4d2_witch_kill_chain_interval "6.0"` 设置固定间隔或随机模式的上限，允许范围为 2～13 秒。
- `l4d2_witch_kill_chain_random "1"` 设置计时方式：`0` 为固定间隔，`1` 为每轮重新随机。
- `l4d2_witch_kill_chain_incap_health "100"` 设置 Witch 每次击倒生还者后回复的生命值，范围为 0～9999，`0` 不回血。
- `l4d2_witch_kill_chain_version` 只读版本号，当前为 `1.1.0`。

实际计时上限为配置值与 `z_witch_burn_time - 0.1` 中的较小值。随机模式每轮在 2 秒到该有效上限之间抽取；有效上限不足 2 秒时自动退化为固定间隔。

## 注意事项

- 火瓶命中后的可见火焰会在下一次定时换目标或击倒换目标时清除，不会在命中瞬间清除。
- 普通武器伤害仍可正常杀死 Witch；插件只阻止原生燃烧期限结束造成的死亡。
- 击倒回血直接加到 Witch 当前生命值上，不受初始最大生命值限制。
- 目标先按三维直线距离排序，再从近到远进行可见性射线检查；墙体和不透明障碍会阻止目标切换，但不计算导航路线可达性。
- 没有任何活动目标、插件被卸载或服务器发生极端停顿时，无法继续刷新燃烧时间。
- 插件中途加载时，已经被惊扰的 Witch 会在首次击倒玩家后纳入管理；新惊扰的 Witch 会立即正常计时。
